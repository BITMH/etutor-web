SUBTOPIK 01

1.1 Pengertian Fungsi, Domain, Julat & Nilai Mutlak (SP 1.1.1–1.1.3)

Suatu hubungan ialah fungsi hanya jika setiap objek dalam domain memetakan kepada tepat satu imej dalam kodomain, iaitu hubungan satu-dengan-satu atau banyak-dengan-satu.

  • Ujian Garis Mencancang: Garis mencancang x = k yang ditarik pada satah Cartes hanya boleh memotong graf pada tepat satu titik bagi setiap x dalam domain supaya graf itu sah sebagai fungsi.
  • Fungsi pecahan f(x) = p/(ax + b) tidak tertakrif apabila penyebut bernilai sifar (ax + b = 0, iaitu x = -b/a).
  • Fungsi nilai mutlak f(x) = |ax + b| memantulkan bahagian graf di bawah paksi-x ke atas paksi-x membentuk huruf V dengan bucu pada y = 0 apabila x = -b/a.

Contoh: Diberi f(x) = |2x - 6| bagi domain -1 <= x <= 5. Tentukan julat bagi f(x).

Penyelesaian: Cari bucu V: 2x - 6 = 0 memberi x = 3 (berada dalam domain -1 <= x <= 5), maka nilai minimum f(3) = 0. Semak hujung domain: f(-1) = |-2 - 6| = 8 dan f(5) = |10 - 6| = 4. Oleh itu julat ialah 0 <= f(x) <= 8.

Tip Penting: Sentiasa semak sama ada titik bucu y = 0 berada di dalam selang domain sebelum menentukan nilai minimum julat nilai mutlak.

SUBTOPIK 02

1.2 Fungsi Gubahan & Fungsi Berulang (SP 1.2.1–1.2.4)

Fungsi gubahan fg(x) bermaksud f(g(x)), iaitu fungsi g bertindak ke atas objek x dahulu diikuti oleh fungsi f ke atas hasil g(x).

  • Susunan penting: Secara amnya fg(x) != gf(x). Tatatanda f^2(x) bermaksud f(f(x)), bukannya [f(x)]^2.
  • Mencari fungsi dalam g(x) daripada fg(x) dan f(x): Gantikan terus g(x) ke dalam ungkapan f, kemudian samakan dengan fg(x).
  • Mencari fungsi luar f(x) daripada fg(x) dan g(x): Tetapkan u = g(x), ungkapkan x dalam sebutan u, gantikan ke dalam fg(x), lalu tukar semula u kepada x.

Contoh: Diberi g(x) = 2x - 1 dan fg(x) = 6x + 5. Cari f(x).

Penyelesaian: Biar u = 2x - 1, maka x = (u + 1)/2. Gantikan: f(u) = 6((u + 1)/2) + 5 = 3(u + 1) + 5 = 3u + 8. Maka f(x) = 3x + 8. Semak: fg(x) = 3(2x - 1) + 8 = 6x + 5.

Tip Penting: Sentiasa semak jawapan dengan menggantikan semula fungsi yang diperoleh ke dalam gubahan fg(x).

SUBTOPIK 03

1.3 Syarat Kewujudan Fungsi Songsang & Pantulan y = x (SP 1.3.1–1.3.2)

Fungsi songsang f^-1 memetakan imej kembali kepada objek asal dan hanya wujud jika f ialah fungsi satu-dengan-satu.

  • Ujian Garis Mengufuk: Suatu fungsi f mempunyai songsangan jika dan hanya jika sebarang garis mengufuk y = k memotong graf f pada paling banyak satu titik.
  • Hubungan simetri: Graf y = f^-1(x) ialah pantulan graf y = f(x) pada garis y = x. Jika (a, b) terletak pada f, maka (b, a) terletak pada f^-1.
  • Ujian identiti gubahan: Dua fungsi f dan g ialah songsangan antara satu sama lain jika dan hanya jika fg(x) = x dan gf(x) = x.

Contoh: Tentukan sama ada fungsi f(x) = x^2 - 4 bagi domain x >= 0 mempunyai fungsi songsang dan nyatakan sebabnya.

Penyelesaian: Bagi domain terhad x >= 0, graf f(x) = x^2 - 4 ialah separuh parabola yang sentiasa menokok. Setiap garis mengufuk memotong graf pada paling banyak satu titik, maka f ialah fungsi satu-dengan-satu dan mempunyai fungsi songsang.

Tip Penting: Fungsi kuadratik boleh mempunyai songsangan apabila domainnya dihadkan kepada satu cabang sahaja (x >= h atau x <= h).

SUBTOPIK 04

1.4 Menentukan Formula Fungsi Songsang f^-1(x) & Songsangan Gubahan (SP 1.3.3)

Kaedah algebra menentukan f^-1(x) melibatkan pertukaran peranan objek dan imej melalui persamaan f(y) = x serta penyelesaian untuk y.

  • Langkah algebra: Biar f^-1(x) = y supaya f(y) = x, kemudian ungkapkan y dalam sebutan x. Bagi fungsi pecahan, kumpulkan semua sebutan y pada satu sisi sebelum memfaktorkan y.
  • Sekatan domain: Untuk f^-1(x) berbentuk pecahan (ax + b)/(cx + d), wajib nyatakan syarat penyebut x != -d/c.
  • Identiti songsangan gubahan: (fg)^-1(x) = g^-1(f^-1(x)), manakala f(x) boleh dicari daripada fg(x) melalui f(x) = (fg)(g^-1(x)).

Contoh: Diberi f(x) = (2x + 3)/(x - 4) dengan x != 4. Cari f^-1(x) dan nyatakan nilai x di mana f^-1 tidak tertakrif.

Penyelesaian: Biar y = f^-1(x), maka (2y + 3)/(y - 4) = x => 2y + 3 = xy - 4x => y(x - 2) = 4x + 3 => f^-1(x) = (4x + 3)/(x - 2), dengan syarat x != 2.

Tip Penting: Jangan lupa menulis sekatan penyebut x != 2 pada jawapan akhir fungsi songsang pecahan.

AMARAN PEMERIKSA #1

ELAKKAN: Menganggap julat bagi f(x) = |ax + b| pada selang [p, q] hanyalah di antara f(p) dan f(q).

TEPAT: Jika titik bucu x = -b/a berada di dalam [p, q], nilai minimum mutlaknya ialah 0, bukannya min(f(p), f(q)).

Tip Skor Exam: Sentiasa hitung nilai f pada bucu dan kedua-dua hujung selang sebelum menulis julat.

AMARAN PEMERIKSA #2

ELAKKAN: Menulis f^2(x) sebagai [f(x)]^2 atau menukar tertib (fg)^-1 kepada f^-1 g^-1.

TEPAT: f^2(x) bermaksud gubahan f(f(x)) dan (fg)^-1(x) = g^-1 f^-1(x) mengikut songsangan berturutan dari luar ke dalam.

Tip Skor Exam: Gunakan analogi memakai dan menanggalkan stoking dan kasut untuk mengingatkan tertib songsangan.

AMARAN PEMERIKSA #3

ELAKKAN: Terlupa menulis sekatan domain seperti x != k bagi fungsi pecahan dan songsangannya.

TEPAT: Setiap fungsi rasional memerlukan penyebut bukan sifar dinyatakan secara eksplisit, misalnya x != 2.

Tip Skor Exam: Samakan penyebut dengan sifar sebagai semakan terakhir selepas memperoleh f^-1(x).

Antara berikut, hubungan manakah yang merupakan suatu fungsi?

Huraian: Hanya hubungan satu kepada satu dan banyak kepada satu ialah fungsi kerana setiap objek mempunyai tepat satu imej.

Soalan 2 / 20 +10 XP

Diberi fungsi f(x) = 5 / (2x - 8). Nyatakan nilai x yang menyebabkan f tidak tertakrif.

Huraian: Fungsi pecahan tidak tertakrif apabila penyebut 2x - 8 = 0, iaitu x = 4.

Soalan 3 / 20 +10 XP

Diberi f(x) = |3x - 6| bagi domain -1 <= x <= 4. Cari julat bagi f(x).

Huraian: Bucu pada x = 2 berada dalam domain, maka nilai minimum ialah f(2) = 0. Hujung domain: f(-1) = |-9| = 9 dan f(4) = |6| = 6. Julat ialah 0 <= f(x) <= 9.

Soalan 4 / 20 +10 XP

Selesaikan persamaan |2x - 5| = 7.

Huraian: 2x - 5 = 7 memberi x = 6; 2x - 5 = -7 memberi 2x = -2 iaitu x = -1.

Soalan 5 / 20 +10 XP

Diberi f(x) = 3x - 2 dan g(x) = x^2 + 1. Cari fg(2).

Huraian: g(2) = 2^2 + 1 = 5. Maka fg(2) = f(5) = 3(5) - 2 = 13.

Soalan 6 / 20 +10 XP

Jika f(x) = 2x + 3 dan g(x) = 4 - x, tentukan ungkapan bagi gf(x).

Huraian: gf(x) = g(2x + 3) = 4 - (2x + 3) = 1 - 2x.

Soalan 7 / 20 +10 XP

Diberi f(x) = 2x - 5. Cari f^2(x).

Huraian: f^2(x) = f(f(x)) = 2(2x - 5) - 5 = 4x - 10 - 5 = 4x - 15.

Soalan 8 / 20 +10 XP

Diberi f(x) = x + 4 dan fg(x) = 3x - 2. Cari g(x).

Huraian: fg(x) = g(x) + 4 = 3x - 2, maka g(x) = 3x - 6.

Soalan 9 / 20 +10 XP

Diberi g(x) = x - 3 dan fg(x) = 2x + 1. Cari f(x).

Huraian: Biar u = x - 3 => x = u + 3. f(u) = 2(u + 3) + 1 = 2u + 7, maka f(x) = 2x + 7.

Soalan 10 / 20 +10 XP

Jika f(x) = 1 / (1 - x) bagi x != 1, tentukan f^3(5).

Huraian: f(5) = 1/(1 - 5) = -1/4. f^2(5) = 1/(1 - (-1/4)) = 4/5. f^3(5) = 1/(1 - 4/5) = 5.

Soalan 11 / 20 +10 XP

Ujian manakah digunakan untuk menentukan sama ada suatu fungsi mempunyai fungsi songsang?

Huraian: Ujian garis mengufuk mengesahkan sama ada fungsi ialah satu-dengan-satu, iaitu syarat kewujudan fungsi songsang.

Soalan 12 / 20 +10 XP

Titik (3, -7) terletak pada graf y = f(x). Koordinat manakah pasti terletak pada graf y = f^-1(x)?

Huraian: Pantulan pada garis y = x menukar koordinat (a, b) kepada (b, a), iaitu (-7, 3).

Soalan 13 / 20 +10 XP

Diberi f(x) = 4x - 7. Cari f^-1(x).

Huraian: f(y) = x => 4y - 7 = x => y = (x + 7)/4.

Soalan 14 / 20 +10 XP

Diberi h(x) = (3x + 1)/(x - 2), x != 2. Cari h^-1(4).

Huraian: h^-1(4) = a bermaksud h(a) = 4. (3a + 1)/(a - 2) = 4 => 3a + 1 = 4a - 8 => a = 9.

Soalan 15 / 20 +10 XP

Diberi g(x) = (5x - 2)/(x + 3), x != -3. Nyatakan nilai x di mana g^-1(x) tidak tertakrif.

Huraian: Songsangan g^-1(x) = (-3x - 2)/(x - 5), tidak tertakrif apabila x = 5.

Soalan 16 / 20 +10 XP

Jika f(x) = 2x + 1 dan g(x) = x - 4, cari (fg)^-1(x).

Huraian: fg(x) = 2(x - 4) + 1 = 2x - 7. Maka (fg)^-1(x) = (x + 7)/2.

Soalan 17 / 20 +10 XP

Fungsi f(x) = x^2 - 6x + 5 mempunyai songsangan apabila domainnya dihadkan kepada x >= k. Cari nilai minimum k.

Huraian: f(x) = (x - 3)^2 - 4 mempunyai paksi simetri pada x = 3. Domain x >= 3 menjadikan fungsi satu-dengan-satu.

Soalan 18 / 20 +10 XP

Diberi f(x) = 3x + k dan f^-1(10) = 2. Hitung nilai pemalar k.

Huraian: f^-1(10) = 2 bermaksud f(2) = 10 => 3(2) + k = 10 => k = 4.

Soalan 19 / 20 +10 XP

Diberi f(x) = mx + c dengan f(1) = 5 dan f(3) = 11. Cari nilai f^-1(17).

Huraian: m = (11 - 5)/(3 - 1) = 3, dan c = 5 - 3(1) = 2. Jadi f(x) = 3x + 2. Selesaikan 3x + 2 = 17 memberi x = 5.

Soalan 20 / 20 +10 XP

Diberi h(x) = 2x + 3 dan g(x) = x/(x - 1), x != 1. Jika hg(p) = 7, cari nilai p.

Huraian: hg(p) = 2[p/(p - 1)] + 3 = 7 => 2p/(p - 1) = 4 => 2p = 4p - 4 => p = 2.
