SUBTOPIK 01

3.1 Tafsiran Geometri Sistem Persamaan Linear 3 Pemboleh Ubah (SP 3.1.1)

Setiap persamaan linear ax + by + cz = d mewakili satu satah dalam ruang tiga dimensi, dan persilangan tiga satah menentukan bilangan penyelesaian sistem.

  • Penyelesaian Unik: Ketiga-tiga satah bersilang pada tepat satu titik (x, y, z).
  • Penyelesaian Tak Terhingga: Penghapusan menghasilkan identiti 0 = 0, bermakna ketiga-tiga satah bersilang sepanjang satu garis sepunya atau bertindih.
  • Tiada Penyelesaian: Penghapusan menghasilkan percanggahan seperti 0 = k (k != 0), bermakna sekurang-kurangnya dua satah selari atau bersilang berpasangan tanpa titik sepunya.

Contoh: Tentukan bilangan penyelesaian bagi sistem: x + y + z = 4 dan 2x + 2y + 2z = 5 dengan persamaan ketiga x - y + z = 2.

Penyelesaian: Darab persamaan pertama dengan 2 memberi 2x + 2y + 2z = 8. Tolakkan dengan 2x + 2y + 2z = 5 menghasilkan 0 = 3 (percanggahan). Maka sistem ini tiada penyelesaian.

Tip Penting: Apabila semua pekali x, y, z berkadaran antara dua persamaan tetapi pemalar di sebelah kanan tidak berkadaran, sistem itu tiada penyelesaian.

SUBTOPIK 02

3.2 Kaedah Penghapusan & Penggantian Sistem 3x3 (SP 3.1.2–3.1.3)

Prinsip utama menyelesaikan sistem tiga pemboleh ubah ialah menghapuskan pemboleh ubah yang SAMA daripada dua pasangan persamaan untuk menurunkan sistem kepada dua pemboleh ubah.

  • Langkah 1: Pilih satu pemboleh ubah paling mudah (misalnya z) dan hapuskannya daripada Persamaan (1) & (2) untuk membentuk Persamaan (4).
  • Langkah 2: Hapuskan pemboleh ubah yang SAMA (z) daripada Persamaan (2) & (3) atau (1) & (3) untuk membentuk Persamaan (5).
  • Langkah 3: Selesaikan sistem 2x2 daripada (4) dan (5), kemudian ganti balik untuk mencari nilai z dan semak ketiga-tiga persamaan.

Contoh: Selesaikan sistem: x + y + z = 6, 2x - y + z = 3, dan x + 2y - z = 2.

Penyelesaian: Tambah (1) dan (3): 2x + 3y = 8 ... (4). Tambah (2) dan (3): 3x + y = 5 => y = 5 - 3x. Ganti ke (4): 2x + 3(5 - 3x) = 8 => 15 - 7x = 8 => x = 1. Maka y = 5 - 3(1) = 2, dan z = 6 - 1 - 2 = 3.

Tip Penting: Sentiasa hapus pemboleh ubah yang sama untuk kedua-dua pasangan pertama supaya tidak terperangkap dengan tiga pemboleh ubah semula.

SUBTOPIK 03

3.3 Persamaan Serentak Linear & Tak Linear (SP 3.2.1)

Gabungan satu persamaan linear dan satu persamaan tak linear diselesaikan secara penggantian untuk membentuk satu persamaan kuadratik.

  • Ungkapkan satu pemboleh ubah daripada persamaan linear (pilih pekali 1 jika ada, atau tulis dalam bentuk pecahan).
  • Gantikan ungkapan tersebut ke dalam persamaan tak linear dan susun kepada bentuk am kuadratik ax^2 + bx + c = 0.
  • Selesaikan kuadratik (pemfaktoran atau rumus kuadratik jika melibatkan tempat perpuluhan) dan hitung setiap pasangan nilai pemboleh ubah kedua.

Contoh: Selesaikan persamaan serentak: x - 2y = 1 dan x^2 + y^2 = 13.

Penyelesaian: Daripada linear: x = 2y + 1. Gantikan ke dalam tak linear: (2y + 1)^2 + y^2 = 13 => 4y^2 + 4y + 1 + y^2 = 13 => 5y^2 + 4y - 12 = 0 => (5y - 6)(y + 2) = 0. Maka y = 6/5 (x = 17/5) atau y = -2 (x = -3).

Tip Penting: Pastikan anda mengkuasadua kurungan penuh (2y + 1)^2 = 4y^2 + 4y + 1 tanpa meninggalkan sebutan tengah 4y.

SUBTOPIK 04

3.4 Aplikasi Masalah Geometri & Pecahan (SP 3.2.2)

Masalah geometri (perimeter, luas, teorem Pythagoras) dan persamaan pecahan dimodelkan kepada sistem persamaan sebelum menapis penyelesaian fizikal yang sah.

  • Bagi persamaan melibatkan pecahan seperti 1/x + 1/y = k, darabkan semua sebutan dengan xy untuk menghapuskan penyebut sebelum penggantian.
  • Untuk panjang, lebar, luas dan masa fizikal, tolak penyelesaian negatif atau sifar dengan menyatakan sebabnya secara jelas.
  • Jika soalan menyatakan 'beri jawapan betul kepada tiga tempat perpuluhan', guna rumus kuadratik x = [-b +/- punca(b^2 - 4ac)]/(2a).

Contoh: Perimeter sebuah segi empat tepat ialah 28 cm dan panjang pepenjurunya ialah 10 cm. Cari panjang dan lebarnya jika panjang > lebar.

Penyelesaian: 2(x + y) = 28 => x + y = 14 => y = 14 - x. Pythagoras: x^2 + y^2 = 100. Ganti: x^2 + (14 - x)^2 = 100 => 2x^2 - 28x + 96 = 0 => x^2 - 14x + 48 = 0 => (x - 8)(x - 6) = 0, jadi panjang = 8 cm dan lebar = 6 cm.

Tip Penting: Gunakan nombor rangkap tiga Pythagoras seperti (6, 8, 10) untuk menyemak kewajaran dimensi segi empat tepat.

AMARAN PEMERIKSA #1

ELAKKAN: Menghapuskan pemboleh ubah berbeza dalam dua langkah pertama sistem 3x3 (contohnya hapus z dahulu, kemudian hapus y).

TEPAT: Kedua-dua gabungan persamaan awal MESTI menghapuskan pemboleh ubah yang SAMA supaya terhasil dua persamaan dalam dua pemboleh ubah yang sama.

Tip Skor Exam: Tandakan pemboleh ubah sasaran yang ingin dihapuskan sebelum memulakan operasi tambah atau tolak.

AMARAN PEMERIKSA #2

ELAKKAN: Melupakan sebutan silang 2ab apabila mengembang (a - b)^2 dalam persamaan serentak tak linear.

TEPAT: Sentiasa kembangkan (a - b)^2 = a^2 - 2ab + b^2 dan darab semua sebutan dengan penyebut jika penggantian berbentuk pecahan.

Tip Skor Exam: Semak pasangan jawapan (x, y) ke dalam kedua-dua persamaan asal.

AMARAN PEMERIKSA #3

ELAKKAN: Tidak memadankan nilai x dan y secara berpasangan atau mengekalkan panjang negatif dalam masalah geometri.

TEPAT: Nyatakan setiap pasangan (x, y) secara jelas dan tolak nilai negatif apabila pemboleh ubah mewakili panjang atau jisim.

Tip Skor Exam: Tulis 'x = ..., y = ... atau x = ..., y = ...' supaya pemarkahan LPM jelas.

Soalan 1 / 20 +10 XP

Apakah tafsiran geometri apabila penghapusan sistem persamaan linear tiga pemboleh ubah menghasilkan pernyataan 0 = 5?

Huraian: Pernyataan palsu 0 = 5 menunjukkan sistem tidak konsisten dan tiada penyelesaian.

Soalan 2 / 20 +10 XP

Diberi sistem: x + y + z = 9, y + z = 6, dan z = 2. Cari nilai x, y dan z.

Huraian: z = 2 => y = 6 - 2 = 4 => x = 9 - 6 = 3.

Soalan 3 / 20 +10 XP

Selesaikan sistem persamaan: x + y - z = 2, 2x - y + z = 7, x + 2y + z = 10.

Huraian: Tambah pers 1 dan 2: 3x = 9 => x = 3. Ganti ke pers 1 dan 3: y - z = -1 dan 2y + z = 7 => 3y = 6 => y = 2, z = 3.

Soalan 4 / 20 +10 XP

Jika 2x + y = 5 dan x^2 + y = 8, cari nilai-nilai x.

Huraian: y = 5 - 2x. Ganti: x^2 + 5 - 2x = 8 => x^2 - 2x - 3 = 0 => (x - 3)(x + 1) = 0 => x = -1 atau x = 3.

Soalan 5 / 20 +10 XP

Antara berikut, sistem linear manakah yang mempunyai penyelesaian tak terhingga?

Huraian: Persamaan kedua ialah 2 kali persamaan pertama (menghasilkan 0 = 0), dan dengan persamaan ketiga membentuk garis persilangan bersama (penyelesaian tak terhingga).

Soalan 6 / 20 +10 XP

Cari titik persilangan bagi garis lurus y = x + 1 dan lengkung y = x^2 - 5.

Huraian: x^2 - 5 = x + 1 => x^2 - x - 6 = 0 => (x - 3)(x + 2) = 0. x = -2 => y = -1; x = 3 => y = 4.

Soalan 7 / 20 +10 XP

Diberi x + 2y + 3z = 14, x - y + z = 2 dan 2x + y - z = 1. Hitung nilai x + y + z.

Huraian: Tambah pers 2 dan 3: 3x = 3 => x = 1. Ganti ke pers 2: -y + z = 1 => z = y + 1. Ganti ke pers 1: 1 + 2y + 3(y + 1) = 14 => 5y = 10 => y = 2, z = 3. Maka x + y + z = 1 + 2 + 3 = 6.

Soalan 8 / 20 +10 XP

Selesaikan persamaan serentak: x - y = 2 dan xy = 15.

Huraian: x = y + 2 => (y + 2)y = 15 => y^2 + 2y - 15 = 0 => y = 3 (x = 5) atau y = -5 (x = -3).

Soalan 9 / 20 +10 XP

Jika 1/x + 1/y = 5/6 dan x + y = 5, cari nilai positif bagi |x - y|.

Huraian: (x + y)/(xy) = 5/6 => 5/(xy) = 5/6 => xy = 6. Dengan x + y = 5, pasangan ialah (2, 3) atau (3, 2), maka |x - y| = 1.

Soalan 10 / 20 +10 XP

Sebuah bakul mengandungi x epal, y oren dan z mangga dengan jumlah 12 biji. Bilangan oren dua kali epal dan jumlah harga RM1(x) + RM2(y) + RM3(z) = RM28. Cari nilai z.

Huraian: y = 2x => 3x + z = 12 dan x + 4x + 3z = 28 => 5x + 3z = 28. Ganti z = 12 - 3x: 5x + 36 - 9x = 28 => 4x = 8 => x = 2, y = 4, z = 6.

Soalan 11 / 20 +10 XP

Persamaan garis lurus y = 2x + c bersilang dengan lengkung x^2 + y^2 = 20 pada titik (2, 4). Cari titik persilangan yang satu lagi.

Huraian: Semak: jika garis melalui (2, 4), 4 = 2(2) + c => c = 0, jadi y = 2x. Ganti ke x^2 + 4x^2 = 20 => 5x^2 = 20 => x = +/-2. Titik satu lagi ialah (-2, -4).

Soalan 12 / 20 +10 XP

Dalam sebuah segi tiga bersudut tegak, hipotenusnya ialah 13 cm dan perimeter ialah 30 cm. Cari beza panjang antara dua sisi yang lain.

Huraian: x + y = 17 dan x^2 + y^2 = 169 => (x + y)^2 - 2xy = 169 => 289 - 169 = 2xy => xy = 60. Maka (x - y)^2 = 169 - 120 = 49 => |x - y| = 7 cm (sisi 5 cm dan 12 cm).

Soalan 13 / 20 +10 XP

Diberi 2x + y - z = 4, x - 2y + 2z = 7 dan 3x + y + z = 14. Cari nilai x.

Huraian: Tambah pers 1 dan 3: 5x + 2y = 18. Darab pers 1 dengan 2 lalu tambah pers 2: 5x = 15 => x = 3.

Soalan 14 / 20 +10 XP

Bilakah persamaan serentak satu linear dan satu tak linear mempunyai tepat satu penyelesaian?

Huraian: b^2 - 4ac = 0 bermaksud garis linear menyentuh lengkung pada tepat satu titik tangen.

Soalan 15 / 20 +10 XP

Selesaikan persamaan serentak 2x - y = 3 dan x^2 - y = 6.

Huraian: y = 2x - 3 => x^2 - (2x - 3) = 6 => x^2 - 2x - 3 = 0 => (x - 3)(x + 1) = 0 => x = -1 atau x = 3.

Soalan 16 / 20 +10 XP

Luas sebidang tanah segi empat tepat ialah 72 m^2 dan perimeternya ialah 34 m. Cari panjang tanah tersebut.

Huraian: x + y = 17, xy = 72 => x^2 - 17x + 72 = 0 => (x - 9)(x - 8) = 0. Panjang ialah 9 m (dan lebar 8 m).

Soalan 17 / 20 +10 XP

Diberi sistem: x + 2y - z = 3, 2x - y + 3z = 6, -x + y + 2z = 5. Cari nilai z.

Huraian: Dengan x = 1, y = 2, z = 2: 1 + 4 - 2 = 3, 2 - 2 + 6 = 6, dan -1 + 2 + 4 = 5, maka z = 2.

Soalan 18 / 20 +10 XP

Jika (2, -1, 3) ialah penyelesaian bagi ax + y + z = 6 dan x + by - z = -4, cari nilai a + b.

Huraian: 2a - 1 + 3 = 6 => 2a = 4 => a = 2. 2 - b - 3 = -4 => -b = -3 => b = 3. Maka a + b = 5.

Soalan 19 / 20 +10 XP

Hasil tambah dua nombor ialah 10 dan hasil tambah kuasa dua kedua-dua nombor itu ialah 58. Cari hasil darab kedua-dua nombor itu.

Huraian: (x + y)^2 = x^2 + y^2 + 2xy => 100 = 58 + 2xy => 2xy = 42 => xy = 21 (nombor 3 dan 7).

Soalan 20 / 20 +10 XP

Dua keluk x^2 + y^2 = 25 dan garis x + y = 7 bersilang pada titik-titik A dan B. Cari panjang tembereng garis AB.

Huraian: x + y = 7 dan x^2 + y^2 = 25 memberi titik (3, 4) dan (4, 3). Jarak AB = punca((4 - 3)^2 + (3 - 4)^2) = punca(2).
