SUBTOPIK 01

4.1 Hukum Indeks & Persamaan Indeks Berpemfaktoran (SP 4.1.1–4.1.2)

Hukum indeks membolehkan ungkapan berkuasa diringkaskan dengan menyamakan asas atau memfaktorkan kuasa sepunya.

  • Hukum asas: a^m * a^n = a^(m+n), a^m / a^n = a^(m-n), (a^m)^n = a^(mn), a^0 = 1 (a != 0), dan a^(-n) = 1/a^n.
  • Jika persamaan mengandungi operasi tambah atau tolak seperti 2^(x+2) + 2^x = 20, faktorkan 2^x(4 + 1) = 20 => 2^x = 4 => x = 2.
  • Bagi persamaan berbentuk p^(2x) - k*p^x + c = 0, guna penggantian u = p^x untuk menjadikannya persamaan kuadratik.

Contoh: Selesaikan persamaan 3^(x+2) - 3^x = 72.

Penyelesaian: Faktorkan 3^x: 3^x(3^2 - 1) = 72 => 3^x(8) = 72 => 3^x = 9 = 3^2, maka x = 2.

Tip Penting: Jangan sekali-kali membatalkan asas apabila terdapat tanda tambah atau tolak di antara sebutan indeks; sentiasa faktorkan dahulu.

SUBTOPIK 02

4.2 Hukum Surd & Penisbahan Penyebut (SP 4.2.1–4.2.5)

Surd ialah nombor tak nisbah dalam bentuk punca kuasa seperti punca(2) atau punca(3), dan penyebut bersurd dinisbahkan dengan mendarab konjugatnya.

  • Pendaraban dan pembahagian surd: punca(a) * punca(b) = punca(ab) dan punca(a)/punca(b) = punca(a/b) bagi a, b > 0.
  • Surd serupa sahaja boleh ditambah/ditolak: punca(50) + punca(8) = 5*punca(2) + 2*punca(2) = 7*punca(2).
  • Konjugat bagi (a + punca(b)) ialah (a - punca(b)), dengan hasil darab bebas surd: (a + punca(b))(a - punca(b)) = a^2 - b.

Contoh: Nisbahkan penyebut dan permudahkan 6 / (punca(5) - punca(2)).

Penyelesaian: Darab pengangka dan penyebut dengan konjugat (punca(5) + punca(2)): 6(punca(5) + punca(2)) / (5 - 2) = 6(punca(5) + punca(2)) / 3 = 2(punca(5) + punca(2)).

Tip Penting: Sentiasa pastikan kedua-dua pengangka dan penyebut didarab dengan konjugat penyebut, bukannya konjugat pengangka.

SUBTOPIK 03

4.3 Hukum Logaritma & Penukaran Asas (SP 4.3.1–4.3.4)

Logaritma ialah songsangan kepada fungsi indeks: a^y = x setara dengan log_a(x) = y bagi a > 0, a != 1 dan x > 0.

  • Tiga hukum asas: log_a(xy) = log_a(x) + log_a(y), log_a(x/y) = log_a(x) - log_a(y), dan log_a(x^n) = n * log_a(x).
  • Nilai khas: log_a(1) = 0, log_a(a) = 1, dan log_a(x) hanya tertakrif apabila x > 0.
  • Rumus penukaran asas: log_a(b) = log_c(b) / log_c(a), serta kes khas log_a(b) = 1 / log_b(a).

Contoh: Diberi log_2(3) = p dan log_2(5) = q. Ungkapkan log_4(45) dalam sebutan p dan q.

Penyelesaian: Tukar asas kepada 2: log_4(45) = log_2(45) / log_2(4) = log_2(3^2 * 5) / 2 = (2*log_2(3) + log_2(5)) / 2 = (2p + q)/2.

Tip Penting: Tukar semua logaritma kepada asas yang sama dengan maklumat soalan sebelum memecahkan nombor kepada faktor perdana.

SUBTOPIK 04

4.4 Persamaan Logaritma, Log Jati (ln) & Aplikasi (SP 4.4.1)

Persamaan a^x = b yang asasnya tidak dapat disamakan diselesaikan dengan mengambil log10 atau ln pada kedua-dua belah persamaan.

  • Logaritma jati ln(x) bermaksud log_e(x) dengan e ~ 2.7183, di mana ln(e) = 1 dan e^(ln k) = k.
  • Semasa menyelesaikan ketaksamaan seperti (0.8)^n < 0.5, bahagikan dengan log(0.8) yang bernilai negatif akan menyongsangkan tanda ketaksamaan menjadi n > log(0.5)/log(0.8).
  • Setiap penyelesaian persamaan logaritma wajib disemak supaya hujah di dalam logaritma sentiasa positif (> 0).

Contoh: Selesaikan persamaan log_3(x + 2) + log_3(x - 4) = 3.

Penyelesaian: Gabungkan log: log_3[(x + 2)(x - 4)] = 3 => (x + 2)(x - 4) = 3^3 = 27 => x^2 - 2x - 8 = 27 => x^2 - 2x - 35 = 0 => (x - 7)(x + 5) = 0. Semak domain x > 4: x = -5 ditolak, maka x = 7 sahaja.

Tip Penting: Sentiasa uji semula punca ke dalam persamaan asal kerana nilai negatif bagi hujah logaritma tidak tertakrif.

AMARAN PEMERIKSA #1

ELAKKAN: Menganggap log_a(x + y) sama dengan log_a(x) + log_a(y), atau log_a(x)/log_a(y) sama dengan log_a(x/y).

TEPAT: log_a(x) + log_a(y) = log_a(xy), manakala log_a(x) - log_a(y) = log_a(x/y). Hasil bahagi dua logaritma tidak sama dengan logaritma hasil bahagi.

Tip Skor Exam: Ingat hanya hasil darab dan hasil bahagi di dalam SATU logaritma yang boleh dipecahkan kepada tambah atau tolak.

AMARAN PEMERIKSA #2

ELAKKAN: Menerima penyelesaian negatif dalam persamaan logaritma seperti log_2(x - 3) apabila x = -1.

TEPAT: Logaritma hanya tertakrif bagi nombor positif, maka mana-mana nilai x yang menjadikan hujah <= 0 wajib ditolak.

Tip Skor Exam: Gantikan jawapan akhir ke dalam setiap ungkapan logaritma asal sebelum memuktamadkan jawapan.

AMARAN PEMERIKSA #3

ELAKKAN: Lupa menterbalikkan tanda ketaksamaan apabila membahagi dengan log(r) yang bernilai negatif (0 < r < 1).

TEPAT: Oleh sebab log10(0.85) < 0, membahagi kedua-dua belah dengan nilai negatif ini menukar '<' kepada '>' dan sebaliknya.

Tip Skor Exam: Semak tanda nilai logaritma asas pecahan (< 1) pada kalkulator sebelum langkah pembahagian.

Soalan 16 / 20 +10 XP

Selesaikan 2^(2x) - 6(2^x) + 8 = 0.

Huraian: Biar u = 2^x: u^2 - 6u + 8 = 0 => (u - 2)(u - 4) = 0 => 2^x = 2 (x = 1) atau 2^x = 4 (x = 2).

Soalan 17 / 20 +10 XP

Jika log_10(x) = 1.4 dan log_10(y) = 0.6, hitung nilai log_10(10x / punca(y)).

Huraian: log_10(10) + log_10(x) - 0.5 log_10(y) = 1 + 1.4 - 0.5(0.6) = 2.4 - 0.3 = 2.1.

Soalan 18 / 20 +10 XP

Suatu bahan radioaktif mereput mengikut M = 200(0.5)^(t/4) gram selepas t tahun. Selepas berapa tahun jisimnya menjadi 25 gram?

Huraian: 200(0.5)^(t/4) = 25 => (0.5)^(t/4) = 1/8 = (0.5)^3 => t/4 = 3 => t = 12 tahun.

Soalan 19 / 20 +10 XP

Diberi p = log_2(3) dan q = log_3(5). Ungkapkan log_2(5) dalam sebutan p dan q.

Huraian: log_2(5) = log_2(3) * log_3(5) = pq.

Soalan 20 / 20 +10 XP

Cari integer terkecil n yang memenuhi ketaksamaan (3/4)^n < 1/2 (diberi log10(3/4) ~ -0.1249, log10(0.5) ~ -0.3010).

Huraian: n * log(3/4) < log(0.5) => n > (-0.3010)/(-0.1249) = 2.41, maka integer terkecil ialah n = 3.
