SUBTOPIK 01

5.1 Janjang Aritmetik: Beza Sepunya d & Sebutan Ke-n (SP 5.1.1–5.1.2)

Janjang aritmetik (JA) ialah jujukan nombor yang setiap sebutannya diperoleh dengan menambah satu pemalar tetap d yang disebut beza sepunya.

  • Syarat JA: T2 - T1 = T3 - T2 = d (pemalar). Jika T2 - T1 != T3 - T2, jujukan bukan JA.
  • Rumus sebutan ke-n: Tn = a + (n - 1)d dengan a ialah sebutan pertama dan d ialah beza sepunya.
  • Untuk mencari sebutan pertama yang melebihi had M, selesaikan ketaksamaan Tn > M dan bundarkan n ke atas kepada integer seterusnya.

Contoh: Dalam suatu JA, T3 = 11 dan T8 = 31. Cari sebutan pertama a, beza sepunya d, dan T15.

Penyelesaian: T8 - T3 = (a + 7d) - (a + 2d) = 5d = 31 - 11 = 20 => d = 4. Ganti ke T3: a + 2(4) = 11 => a = 3. Maka T15 = 3 + 14(4) = 59.

Tip Penting: Menolak dua sebutan yang diketahui menghapuskan a serta-merta dan mempercepatkan pencarian d.

SUBTOPIK 02

5.2 Hasil Tambah Janjang Aritmetik & Hubungan Tn = Sn - S(n-1) (SP 5.1.3–5.1.4)

Hasil tambah n sebutan pertama JA dihitung menggunakan rumus Sn, manakala sebutan individu boleh diekstrak daripada rumus Sn melalui beza hasil tambah.

  • Dua bentuk rumus hasil tambah JA: Sn = (n/2)[2a + (n - 1)d] dan Sn = (n/2)(a + l) apabila sebutan terakhir l diketahui.
  • Hubungan sejagat: a = T1 = S1, dan bagi n >= 2, Tn = Sn - S(n - 1).
  • Hasil tambah daripada sebutan ke-p hingga ke-q ialah Sq - S(p - 1), bukannya Sq - Sp (contohnya T5 hingga T12 ialah S12 - S4).

Contoh: Diberi hasil tambah n sebutan pertama suatu JA ialah Sn = 2n^2 + 3n. Cari sebutan ke-5, T5.

Penyelesaian: T5 = S5 - S4 = [2(25) + 3(5)] - [2(16) + 3(4)] = 65 - 44 = 21. (Cara umum: Tn = Sn - S(n-1) = 4n + 1, maka T5 = 21).

Tip Penting: Gunakan T5 = S5 - S4 terus jika hanya satu sebutan bernombor tertentu yang diminta.

SUBTOPIK 03

5.3 Janjang Geometri: Nisbah Sepunya r, Tn & Sn (SP 5.2.1–5.2.3)

Janjang geometri (JG) ialah jujukan yang setiap sebutan selepas pertama diperoleh dengan mendarab sebutan sebelumnya dengan pemalar tetap r.

  • Syarat JG: T2 / T1 = T3 / T2 = r (pemalar bukan sifar).
  • Rumus sebutan ke-n: Tn = a * r^(n - 1).
  • Rumus hasil tambah n sebutan pertama: Sn = a(r^n - 1)/(r - 1) bagi |r| > 1, atau Sn = a(1 - r^n)/(1 - r) bagi |r| < 1.

Contoh: Tiga sebutan berturutan suatu JG ialah k - 2, k + 2, dan 3k - 2 (semua positif). Cari nilai k dan nisbah sepunya r.

Penyelesaian: (k + 2)/(k - 2) = (3k - 2)/(k + 2) => (k + 2)^2 = (k - 2)(3k - 2) => k^2 + 4k + 4 = 3k^2 - 8k + 4 => 2k^2 - 12k = 0 => k = 6 (tolak k = 0 kerana sebutan negatif). Sebutan ialah 4, 8, 16 dengan r = 2.

Tip Penting: Sentiasa guna syarat T2^2 = T1 * T3 untuk membina persamaan kuadratik apabila tiga sebutan berturutan JG diberi dalam sebutan pemalar.

SUBTOPIK 04

5.4 Hasil Tambah Ketakterhinggaan & Aplikasi JG (SP 5.2.4–5.2.5)

Apabila |r| < 1, kuasa r^n menghampiri sifar apabila n menuju infiniti, menjadikan hasil tambah ketakterhinggaan menumpu kepada nilai terhingga.

  • Syarat penumpuan: -1 < r < 1 (iaitu |r| < 1), dengan S_inf = a / (1 - r).
  • Menukar perpuluhan berulang seperti 0.272727... kepada pecahan: tulis sebagai JG 0.27 + 0.0027 + ... dengan a = 0.27 dan r = 0.01, lalu guna S_inf.
  • Dalam masalah faedah kompaun atau susut nilai tahunan pada kadar p%, selepas n tahun lengkap nilainya ialah P(1 +/- p/100)^n (kuasa n, bukan n - 1).

Contoh: Ungkapkan perpuluhan berulang 0.363636... sebagai pecahan termudah menggunakan hasil tambah ketakterhinggaan.

Penyelesaian: 0.363636... = 0.36 + 0.0036 + 0.000036 + ... dengan a = 0.36 dan r = 0.01. S_inf = 0.36 / (1 - 0.01) = 0.36 / 0.99 = 36/99 = 4/11.

Tip Penting: Periksa bilangan digit berulang: 1 digit berulang memberi r = 0.1, 2 digit berulang memberi r = 0.01.

AMARAN PEMERIKSA #1

ELAKKAN: Mengira hasil tambah dari sebutan ke-4 hingga sebutan ke-10 sebagai S10 - S4.

TEPAT: S10 - S4 membuang sebutan ke-4 sekali; hasil tambah yang tepat ialah S10 - S3.

Tip Skor Exam: Sentiasa tolak S(m - 1) apabila bermula daripada sebutan ke-m.

AMARAN PEMERIKSA #2

ELAKKAN: Tertinggal kurungan apabila mengira sebutan JG dengan nisbah sepunya negatif, seperti menulis -2^4 = -16 bukannya (-2)^4 = 16.

TEPAT: Setiap penggantian r negatif ke dalam a*r^(n-1) mesti dikurungkan dengan ketat sebelum menekan kuasa di kalkulator.

Tip Skor Exam: Semak tanda berselang-seli (+, -, +, -) bagi jujukan JG dengan r < 0.

AMARAN PEMERIKSA #3

ELAKKAN: Menggunakan kuasa (n - 1) dalam masalah faedah kompaun bank selepas n tahun, sedangkan wang asal ialah T0 sebelum tahun pertama.

TEPAT: Selepas 1 tahun nilainya P(1 + i)^1, maka selepas n tahun lengkap nilainya ialah P(1 + i)^n.

Tip Skor Exam: Bezakan indeks tahun mula T1 (gaji tahun pertama) dengan nilai permulaan T0 (deposit awal).

Soalan 7 / 20 +10 XP

Tiga sebutan berturutan suatu janjang geometri ialah x - 2, x + 2 dan 3x - 2 dengan semua sebutan positif. Cari nilai x.

Huraian: (x + 2)^2 = (x - 2)(3x - 2) => x^2 + 4x + 4 = 3x^2 - 8x + 4 => 2x^2 - 12x = 0 => x = 6 (sebutan 4, 8, 16).

Soalan 8 / 20 +10 XP

Soalan 9 / 20 +10 XP

Soalan 10 / 20 +10 XP

Sebiji bola dijatuhkan dari ketinggian 16 m dan melantun semula kepada 3/4 daripada ketinggian sebelumnya setiap kali. Hitung jumlah jarak tegak yang dilalui bola sehingga berhenti.

Huraian: Jatuh pertama 16 m + dua kali jumlah lantunan menaik/menurun: 16 + 2[12 / (1 - 3/4)] = 16 + 2(48) = 112 m.

Soalan 11 / 20 +10 XP

Dalam suatu janjang geometri, T2 = 12 dan T5 = 324. Cari nisbah sepunya r.

Huraian: T5 / T2 = r^3 = 324 / 12 = 27 => r = 3.

Soalan 12 / 20 +10 XP

Apakah syarat bagi sesuatu janjang geometri a, ar, ar^2, ... mempunyai hasil tambah ketakterhinggaan?

Huraian: S_inf hanya menumpu apabila |r| < 1, iaitu -1 < r < 1.

Soalan 13 / 20 +10 XP

Cari bilangan minimum sebutan bagi janjang aritmetik 4, 11, 18, ... supaya hasil tambahnya melebihi 200.

Huraian: (n/2)[8 + 7(n - 1)] > 200 => n(7n + 1) > 400. Jika n = 7: 7(50) = 350 <= 400; n = 8: 8(57) = 456 > 400. Jadi n = 8.

Soalan 14 / 20 +10 XP

Jika hasil tambah dari sebutan ke-5 hingga sebutan ke-12 suatu janjang aritmetik diperlukan, ungkapan manakah yang betul?

Huraian: T5 + ... + T12 = S12 - S4.

Soalan 15 / 20 +10 XP

Suatu janjang geometri mempunyai sebutan pertama 5 dan S_inf = 15. Cari nisbah sepunya r.

Huraian: 5 / (1 - r) = 15 => 1 - r = 1/3 => r = 2/3.

Soalan 16 / 20 +10 XP

Dalam suatu janjang aritmetik, hasil tambah tiga sebutan pertama ialah 21 dan hasil darabnya ialah 280. Jika d > 0, cari beza sepunya d.

Huraian: Biar sebutan (m - d), m, (m + d). 3m = 21 => m = 7. (7 - d)(7)(7 + d) = 280 => 49 - d^2 = 40 => d^2 = 9 => d = 3.

Soalan 17 / 20 +10 XP

Sebuah kereta bernilai RM80,000 menyusut nilai sebanyak 10% setiap tahun berbanding tahun sebelumnya. Berapakah nilainya selepas 3 tahun?

Huraian: Nilai selepas 3 tahun = 80,000 * (0.9)^3 = 80,000 * 0.729 = RM58,320.

Soalan 18 / 20 +10 XP

Cari nilai terkecil integer n supaya hasil tambah n sebutan pertama JG 2 + 6 + 18 + ... melebihi 500.

Huraian: Sn = 2(3^n - 1)/(3 - 1) = 3^n - 1 > 500 => 3^n > 501. Kerana 3^5 = 243 dan 3^6 = 729, maka n = 6.

Soalan 19 / 20 +10 XP

Diberi suatu janjang aritmetik dengan d = -4 dan T1 = 35. Berapakah bilangan sebutan positif dalam janjang ini?

Huraian: 35 + (n - 1)(-4) > 0 => 39 - 4n > 0 => n < 9.75, maka terdapat 9 sebutan positif (T9 = 3, T10 = -1).

Soalan 20 / 20 +10 XP

Hasil tambah sebutan ke-2 dan ke-3 suatu JG ialah 12, manakala hasil tambah sebutan ke-4 dan ke-5 ialah 48 (dengan r > 0). Cari nilai a.

Huraian: (T4 + T5)/(T2 + T3) = r^2 = 48/12 = 4 => r = 2 (kerana r > 0). Ganti ke ar + ar^2 = 12 => 2a + 4a = 12 => a = 2.
