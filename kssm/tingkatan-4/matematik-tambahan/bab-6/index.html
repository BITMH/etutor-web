SUBTOPIK 01

6.1 Hubungan Linear, Garis Penyuaian Terbaik & Pintasan (SP 6.1.1–6.1.3)

Garis penyuaian terbaik ialah garis lurus yang melalui seberapa banyak titik plot dan menyeimbangkan bilangan titik yang tidak berada pada garis secara sekata di kedua-dua belah.

  • Kecerunan m = (Y2 - Y1)/(X2 - X1) MESTI dihitung menggunakan dua titik berjauhan yang berada tepat di atas garis penyuaian terbaik, bukan titik data yang terkeluar.
  • Pintasan-Y (c) ialah nilai pada paksi mencancang Y apabila paksi mengufuk X = 0.
  • Dalam kertas graf SPM, gunakan skala seragam yang mudah seperti 1, 2, 5 atau gandaannya bagi setiap 2 cm; elakkan skala ganjil seperti 3, 4, 6 atau 7.

Contoh: Suatu garis lurus penyuaian terbaik yang memplot y/x melawan x^2 melalui titik (1, 5) dan (4, 14). Cari persamaan yang menghubungkan y dan x.

Penyelesaian: Kecerunan m = (14 - 5)/(4 - 1) = 9/3 = 3. Ganti (1, 5) ke Y = mX + c: 5 = 3(1) + c => c = 2. Maka y/x = 3x^2 + 2 => y = 3x^3 + 2x.

Tip Penting: Sentiasa gantikan semula ungkapan paksi Y dan X pada langkah terakhir untuk memperoleh hubungan asal y dalam sebutan x.

SUBTOPIK 02

6.2 Menukar Persamaan Tak Linear kepada Y = mX + c (SP 6.2.1)

Penglinearan menukar persamaan tak linear kepada Y = mX + c dengan syarat kecerunan m dan pintasan-Y c merupakan pemalar semata-mata (bebas daripada x dan y).

  • Jenis pecahan/polinomial: Misalnya y = px^2 + qx dibahagi dengan x menjadi y/x = px + q (Y = y/x, X = x, m = p, c = q).
  • Jenis salingan: Misalnya y = a/x + b memberi Y = y, X = 1/x, m = a, c = b.
  • Jenis kuasa dan eksponen: Ambil log10 pada kedua-dua belah! Bagi y = ab^x => log10(y) = (log10 b)x + log10 a; bagi y = ax^n => log10(y) = n log10(x) + log10 a.

Contoh: Tukarkan persamaan tak linear y = p * q^x kepada bentuk linear Y = mX + c dan nyatakan ungkapan bagi Y, X, m dan c.

Penyelesaian: Ambil log10 kedua-dua belah: log10(y) = log10(p * q^x) = log10(p) + x log10(q). Banding dengan Y = mX + c: Y = log10(y), X = x, m = log10(q), dan c = log10(p).

Tip Penting: Pastikan pemboleh ubah berkuasa atau dalam eksponen diturunkan menggunakan hukum logaritma sebelum membandingkan dengan Y = mX + c.

SUBTOPIK 03

6.3 Menentukan Nilai Pemalar daripada Graf Garis Lurus (SP 6.2.1–6.3.1)

Apabila graf garis lurus telah dilukis atau diberi kecerunan dan pintasan-Y, nilai pemalar asal diperoleh dengan memadankan pekali dan menyongsangkan logaritma jika perlu.

  • Jika Y = log10(y) dan graf mempunyai pintasan-Y = c, maka pemalar asal ialah p = 10^c.
  • Jika pintasan-Y tidak kelihatan pada graf (X bermula bukan dari 0), guna koordinat dua titik atas garis lurus untuk membentuk dua persamaan serentak bagi mencari m dan c.
  • Jika suatu titik data dalam eksperimen terkeluar jauh daripada garis penyuaian terbaik, titik itu dikenal pasti sebagai titik ralat pengukuran.

Contoh: Graf log10(y) melawan log10(x) ialah garis lurus dengan kecerunan 2 dan melalui titik (1, 5). Jika y = ax^b, cari nilai a dan b.

Penyelesaian: Persamaan linear ialah log10(y) = b log10(x) + log10(a). Maka b = kecerunan = 2. Ganti (1, 5): 5 = 2(1) + log10(a) => log10(a) = 3 => a = 10^3 = 1000.

Tip Penting: Apabila titik (X, Y) diberi, ingat bahawa nilai X dan Y pada graf log10 sudah merupakan log10(x) dan log10(y), bukannya nilai x dan y asal.

SUBTOPIK 04

6.4 Aplikasi Hukum Linear dalam Sains & Kejuruteraan (SP 6.3.1)

Hukum Linear membolehkan saintis mengesahkan model matematik seperti ayunan bandul atau pertumbuhan bakteria dan membuat ramalan nilai.

  • Model bandul T^2 = (4 pi^2 / g) l menghubungkan Y = T^2 dengan X = l melalui garis lurus menerusi asalan dengan kecerunan 4 pi^2 / g.
  • Jika soalan memberi nilai x dan meminta nilai y daripada graf xy melawan x, baca nilai xy dahulu pada graf, kemudian bahagikan dengan x untuk mendapat y.
  • Ramalan nilai di dalam julat data disebut interpolasi, manakala di luar julat data disebut ekstrapolasi.

Contoh: Dalam eksperimen Hukum Linear bagi persamaan y = ax^2 + bx, graf y/x melawan x memotong paksi mencancang di 4 dan mempunyai kecerunan -2. Hitung nilai y apabila x = 3.

Penyelesaian: y/x = -2x + 4 (sepadan dengan a = -2, b = 4). Apabila x = 3: y/3 = -2(3) + 4 = -2 => y = -6.

Tip Penting: Jangan silap menganggap bacaan paksi mencancang (-2) ialah nilai y; sentiasa selesaikan Y = y/x untuk y.

AMARAN PEMERIKSA #1

ELAKKAN: Memasukkan pemboleh ubah x atau y ke dalam kecerunan m atau pintasan c semasa menulis bentuk Y = mX + c.

TEPAT: Kecerunan m dan pintasan c mesti mengandungi pemalar sahaja; semua pemboleh ubah x dan y mesti berada dalam Y dan X.

Tip Skor Exam: Semak m dan c anda: pastikan tiada huruf x atau y muncul di dalamnya.

AMARAN PEMERIKSA #2

ELAKKAN: Membaca koordinat graf Y = xy atau Y = y/x secara terus sebagai nilai y.

TEPAT: Nilai pada paksi mencancang ialah ungkapan Y penuh (misalnya xy = 15), maka y mesti dikira sebagai 15/x.

Tip Skor Exam: Sentiasa tulis label paksi penuh sebelum menggantikan nombor dari graf.

AMARAN PEMERIKSA #3

ELAKKAN: Mengira kecerunan garis penyuaian terbaik menggunakan dua titik daripada jadual data yang tidak terletak di atas garis.

TEPAT: Pilih dua titik yang jelas berada TEPAT di atas garis lurus penyuaian terbaik dan berjauhan antara satu sama lain.

Tip Skor Exam: Tandakan dua titik baharu di atas garis lurus (contohnya pada persilangan grid) untuk mengira kecerunan.

Soalan 1 / 20 +10 XP

Persamaan tak linear y = px^3 - qx ditukar kepada bentuk linear Y = mX + c dengan membahagikan kedua-dua belah dengan x. Apakah pemboleh ubah pada paksi-X dan kecerunan m?

Huraian: y/x = px^2 - q. Membandingkan dengan Y = mX + c memberi Y = y/x, X = x^2, m = p, c = -q.

Soalan 2 / 20 +10 XP

Diberi hubungan tak linear y = ab^x. Apabila log10(y) diplot melawan x, apakah kecerunan dan pintasan-Y graf garis lurus tersebut?

Huraian: log10(y) = (log10 b)x + log10 a, maka m = log10(b) dan c = log10(a).

Soalan 3 / 20 +10 XP

Graf log10(y) melawan x ialah satu garis lurus melalui (0, 2) dan (3, 8). Jika y = pq^x, cari nilai p dan q.

Huraian: log10(p) = pintasan-Y = 2 => p = 10^2 = 100. Kecerunan = (8 - 2)/(3 - 0) = 2 => log10(q) = 2 => q = 100.

Soalan 4 / 20 +10 XP

Antara berikut, hubungan manakah yang menghasilkan graf garis lurus apabila y/x diplot melawan 1/x^2?

Huraian: Bahagi y = ax + b/x dengan x memberi y/x = a + b(1/x^2), maka Y = y/x dan X = 1/x^2 membentuk garis lurus.

Soalan 5 / 20 +10 XP

Suatu graf y/x melawan x^2 melalui titik (2, 7) dan mempunyai pintasan pada paksi mencancang ialah 3. Cari nilai y apabila x = 2.

Huraian: Kecerunan m = (7 - 3)/(2 - 0) = 2, maka y/x = 2x^2 + 3. Apabila x = 2: y/2 = 2(4) + 3 = 11 => y = 22.

Soalan 6 / 20 +10 XP

Dalam eksperimen Hukum Linear, persamaan y = k x^n diplot sebagai log10(y) melawan log10(x). Jika kecerunan graf ialah -1.5 dan pintasan-Y ialah 0.3010, cari nilai n dan k (10^0.3010 = 2).

Huraian: log10(y) = n log10(x) + log10(k). Maka n = kecerunan = -1.5 dan log10(k) = 0.3010 => k = 2.

Soalan 7 / 20 +10 XP

Diberi xy = a/x + b. Jika satu garis lurus dilukis dengan paksi mengufuk X = 1/x, apakah ungkapan pada paksi mencancang Y?

Huraian: xy = a(1/x) + b sudah berada dalam bentuk Y = mX + c dengan Y = xy dan X = 1/x.

Soalan 8 / 20 +10 XP

Garis lurus bagi graf 1/y melawan x melalui titik (1, 4) dan (3, 10). Tentukan persamaan y dalam sebutan x.

Huraian: m = (10 - 4)/(3 - 1) = 3. 4 = 3(1) + c => c = 1. Jadi 1/y = 3x + 1 => y = 1/(3x + 1).

Soalan 9 / 20 +10 XP

Jika y = 5 e^(kx) dilinearkan kepada ln(y) = mx + c, apakah nilai c?

Huraian: ln(y) = kx + ln(5), maka kecerunan m = k dan pintasan c = ln 5.

Soalan 10 / 20 +10 XP

Suatu pemboleh ubah x dan y dihubungkan oleh p/y = q/x^2 + 1. Apabila 1/y diplot melawan 1/x^2, apakah kecerunannya?

Huraian: 1/y = (q/p)(1/x^2) + 1/p, maka kecerunan graf garis lurus ialah q / p.

Soalan 11 / 20 +10 XP

Mengapakah skala seperti 3 unit per 2 cm tidak digalakkan semasa melukis graf Hukum Linear?

Huraian: Skala 1, 2 atau 5 memudahkan pembahagian 10 petak kecil (0.1, 0.2, 0.5) berbanding skala 3 yang menghasilkan pecahan berulang.

Soalan 12 / 20 +10 XP

Diberi hubungan y = a(x - 2)^2 + b. Jika y diplot melawan (x - 2)^2, garis lurus mempunyai kecerunan 4 dan memotong paksi-Y di -5. Cari nilai y apabila x = 5.

Huraian: y = 4(x - 2)^2 - 5. Apabila x = 5: y = 4(5 - 2)^2 - 5 = 4(9) - 5 = 31.

Soalan 13 / 20 +10 XP

Graf x^2 y melawan x mempunyai kecerunan -3 dan melalui titik (2, 4). Hitung nilai y apabila x = 1.

Huraian: x^2 y = -3x + c. Ganti (2, 4): 4 = -3(2) + c => c = 10. Jadi x^2 y = -3x + 10. Pada x = 1: 1^2 y = -3(1) + 10 = 7.

Soalan 14 / 20 +10 XP

Diberi graf log2(y) melawan x ialah garis lurus dengan persamaan log2(y) = 3x - 1. Ungkapkan y dalam sebutan x.

Huraian: y = 2^(3x - 1) = 2^(-1) * (2^3)^x = (1/2) * 8^x.

Soalan 15 / 20 +10 XP

Dalam satu eksperimen, enam titik diplot dan lima daripadanya terletak hampir pada satu garis lurus manakala satu titik berada jauh daripada garis. Apakah tindakan terbaik semasa melukis garis penyuaian terbaik?

Huraian: Titik yang menyimpang jauh dianggap ralat eksperimen dan diabaikan ketika melukis garis penyuaian terbaik.

Soalan 16 / 20 +10 XP

Persamaan y = a/x + b x diubah menjadi bentuk linear dengan Y = xy. Apakah ungkapan bagi X, kecerunan dan pintasan?

Huraian: Darab dengan x: xy = bx^2 + a. Maka Y = xy, X = x^2, m = b, dan c = a.

Soalan 17 / 20 +10 XP

Diberi hubungan punca(y) = m x + c. Jika kecerunan garis ialah 2 dan pintasan pada paksi mencancang ialah 1, cari nilai y apabila x = 3.

Huraian: punca(y) = 2x + 1. Apabila x = 3: punca(y) = 2(3) + 1 = 7 => y = 49.

Soalan 18 / 20 +10 XP

Suatu garis lurus memplot y/x^2 melawan x dan memotong paksi-X pada x = 4 serta paksi-Y pada 8. Cari persamaan y dalam sebutan x.

Huraian: Kecerunan m = (0 - 8)/(4 - 0) = -2 dan pintasan-Y c = 8. Maka y/x^2 = -2x + 8 => y = -2x^3 + 8x^2.

Soalan 19 / 20 +10 XP

Diberi graf ln(y) melawan ln(x) melalui titik (2, 7) dan (4, 11). Jika y = A x^k, cari nilai k.

Huraian: ln(y) = k ln(x) + ln(A). Kecerunan k = (11 - 7)/(4 - 2) = 4/2 = 2.

Soalan 20 / 20 +10 XP

Apabila garis lurus Y = 0.5X + 2 mewakili hubungan antara y/x dengan 1/x, cari nilai y apabila x = 0.5.

Huraian: y/x = 0.5/x + 2 => y = 0.5 + 2x. Pada x = 0.5: y = 0.5 + 2(0.5) = 1.5.
