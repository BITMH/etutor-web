SUBTOPIK 01

7.1 Pembahagi Tembereng Garis & Nisbah m : n (SP 7.1.1–7.1.2)

Titik P(x, y) yang membahagi tembereng garis antara A(x1, y1) dan B(x2, y2) dengan nisbah AP : PB = m : n ditentukan melalui purata berpemberat silang.

  • Rumus pembahagi tembereng: P = ( (n x1 + m x2)/(m + n), (n y1 + m y2)/(m + n) ). Apabila m = n = 1, ia menjadi titik tengah.
  • Perangkap nisbah berantai: Jika diberi 3AP = 2AB, maka AP/AB = 2/3, bermakna PB = 3 - 2 = 1 bahagian, jadi AP : PB = 2 : 1.
  • Koordinat titik boleh dicari songsang (mencari titik hujung B atau nisbah m : n) dengan membandingkan komponen x atau komponen y secara berasingan.

Contoh: Titik P membahagi tembereng garis AB dengan A(-2, 4) dan B(8, -1) mengikut nisbah AP : PB = 2 : 3. Cari koordinat P.

Penyelesaian: x = [3(-2) + 2(8)] / (2 + 3) = (-6 + 16)/5 = 2. y = [3(4) + 2(-1)] / 5 = (12 - 2)/5 = 2. Maka P ialah (2, 2).

Tip Penting: Sentiasa darab silang: m darab koordinat jauh B dan n darab koordinat jauh A.

SUBTOPIK 02

7.2 Garis Lurus Selari, Serenjang & Jarak Terdekat (SP 7.2.1–7.2.2)

Dua garis lurus bukan mencancang adalah selari jika m1 = m2 dan berserenjang jika hasil darab kecerunannya m1 * m2 = -1.

  • Tiga bentuk persamaan garis lurus: bentuk kecerunan y = mx + c, bentuk am ax + by + c = 0, dan bentuk pintasan x/a + y/b = 1.
  • Pembahagi dua sama serenjang bagi AB melalui titik tengah AB dan mempunyai kecerunan m = -1 / m_AB.
  • Jarak terdekat dari titik C ke garis AB ialah panjang garis serenjang dari C ke titik persilangan Q pada AB.

Contoh: Cari persamaan pembahagi dua sama serenjang bagi tembereng garis yang menyambungkan A(1, 2) dan B(5, 10).

Penyelesaian: Titik tengah M = ((1+5)/2, (2+10)/2) = (3, 6). Kecerunan AB = (10 - 2)/(5 - 1) = 2. Kecerunan serenjang m = -1/2. Persamaan: y - 6 = (-1/2)(x - 3) => 2y - 12 = -x + 3 => x + 2y = 15.

Tip Penting: Pastikan anda menggunakan koordinat titik tengah (bukan A atau B) dan kecerunan negatif salingan -1/m_AB.

SUBTOPIK 03

7.3 Luas Poligon (Kaedah Tali Kasut) & Titik Segaris (SP 7.3.1–7.3.3)

Luas poligon dengan bucu-bucu tersusun mengikut lawan arah jam dihitung menggunakan kaedah tali kasut (determinan susun koordinat).

  • Susun bucu mengikut turutan perimeter dan ulang bucu pertama di hujung: Luas = (1/2) |(x1 y2 + x2 y3 + ... + xn y1) - (x2 y1 + x3 y2 + ... + x1 yn)|.
  • Tiga titik A, B, C adalah segaris jika Luas segi tiga ABC = 0 (atau kecerunan AB = kecerunan BC).
  • Jika luas segi tiga diberi sebagai L dan salah satu koordinat mengandungi pemalar k, penyelesaian |U| = 2L menghasilkan DUA kes: U = 2L dan U = -2L.

Contoh: Bucu-bucu sebuah segi tiga ialah A(1, 2), B(5, 2) dan C(3, k). Jika luas segi tiga ialah 8 unit^2, cari nilai-nilai k.

Penyelesaian: Luas = (1/2) |[(1)(2) + (5)(k) + (3)(2)] - [(5)(2) + (3)(2) + (1)(k)]| = (1/2)|(8 + 5k) - (16 + k)| = (1/2)|4k - 8| = 8 => |4k - 8| = 16. Kes 1: 4k - 8 = 16 => k = 6. Kes 2: 4k - 8 = -16 => k = -2.

Tip Penting: Jangan sekali-kali membuang tanda nilai mutlak |...| sebelum menyamakannya dengan +/- (2 * Luas).

SUBTOPIK 04

7.4 Persamaan Lokus Titik Bergerak P(x, y) (SP 7.4.1)

Lokus ialah laluan titik bergerak P(x, y) yang mematuhi syarat jarak geometri, ditukarkan kepada persamaan algebra melalui rumus jarak Euclid.

  • Jarak tetap r dari titik A(a, b): PA = r => (x - a)^2 + (y - b)^2 = r^2 (menghasilkan persamaan bulatan).
  • Sama jarak dari dua titik tetap A dan B: PA = PB => PA^2 = PB^2 (menghasilkan persamaan garis lurus pembahagi dua sama serenjang).
  • Nisbah jarak tetap PA : PB = m : n: n * PA = m * PB => n^2 * PA^2 = m^2 * PB^2 (menghasilkan persamaan bulatan jika m != n).

Contoh: Cari persamaan lokus titik bergerak P(x, y) supaya jaraknya dari A(2, 0) adalah dua kali jaraknya dari B(-1, 0).

Penyelesaian: PA = 2 PB => PA^2 = 4 PB^2 => (x - 2)^2 + y^2 = 4[(x + 1)^2 + y^2] => x^2 - 4x + 4 + y^2 = 4x^2 + 8x + 4 + 4y^2 => 3x^2 + 3y^2 + 12x = 0 => x^2 + y^2 + 4x = 0.

Tip Penting: Ingat untuk mengkuasadua faktor nisbah (2^2 = 4) bersama-sama ungkapan jarak PB^2.

AMARAN PEMERIKSA #1

ELAKKAN: Menukar susunan m dan n dalam rumus pembahagi tembereng sehingga mendarab m dengan A dan n dengan B.

TEPAT: Jika AP : PB = m : n, pemberat m mesti didarab dengan titik hujung bertentangan B(x2, y2) dan n dengan A(x1, y1).

Tip Skor Exam: Semak kewajaran titik P: jika AP < PB (m < n), koordinat P mesti lebih dekat dengan A berbanding B.

AMARAN PEMERIKSA #2

ELAKKAN: Mengabaikan punca kedua daripada tanda nilai mutlak semasa mencari koordinat bucu daripada luas poligon.

TEPAT: Persamaan |f(k)| = 2L sentiasa memberi dua kes f(k) = 2L dan f(k) = -2L, mewakili titik di kedua-dua sisi tapak.

Tip Skor Exam: Tulis simbol +/- 2L secara automatik sebaik sahaja membuka kurungan nilai mutlak.

AMARAN PEMERIKSA #3

ELAKKAN: Lupa mengkuasadua nisbah dalam lokus PA : PB = 3 : 2 dan hanya menulis 2 PA^2 = 3 PB^2.

TEPAT: 2 PA = 3 PB apabila dikuasadua menjadi 4 PA^2 = 9 PB^2.

Tip Skor Exam: Tulis persamaan nisbah PA/PB = m/n dan darab silang n*PA = m*PB dahulu sebelum mengkuasadua kedua-dua belah.

Soalan 1 / 20 +10 XP

Titik P membahagi tembereng garis yang menyambungkan A(-3, 5) dan B(7, -5) dengan nisbah AP : PB = 3 : 2. Cari koordinat P.

Huraian: x = [2(-3) + 3(7)]/5 = 15/5 = 3; y = [2(5) + 3(-5)]/5 = -5/5 = -1. Koordinat P ialah (3, -1).

Soalan 2 / 20 +10 XP

Diberi garis lurus 2x + 4y = 9 adalah serenjang dengan garis lurus y = kx + 3. Cari nilai k.

Huraian: y = -0.5x + 9/4 mempunyai kecerunan m1 = -1/2. Untuk serenjang, (-1/2)k = -1 => k = 2.

Soalan 3 / 20 +10 XP

Persamaan garis lurus dalam bentuk pintasan ialah x/4 - y/6 = 1. Nyatakan kecerunannya.

Huraian: y/6 = x/4 - 1 => y = (6/4)x - 6 = (3/2)x - 6, maka kecerunan ialah 3/2.

Soalan 4 / 20 +10 XP

Cari koordinat titik persilangan antara garis lurus 2x + y = 7 dengan pembahagi dua sama serenjang tembereng yang menyambungkan (0, 0) dan (4, 4).

Huraian: Titik tengah ialah (2, 2) dan kecerunan tembereng ialah 1, maka pembahagi dua sama serenjang ialah y - 2 = -1(x - 2) => x + y = 4. Selesaikan 2x + y = 7 dan x + y = 4 memberi x = 3 dan y = 1.

Soalan 5 / 20 +10 XP

Titik P(2, 3), Q(4, 7) dan R(k, 11) adalah segaris. Cari nilai k.

Huraian: Kecerunan PQ = (7 - 3)/(4 - 2) = 2. Samakan dengan QR: (11 - 7)/(k - 4) = 2 => 4 = 2(k - 4) => k = 6.

Soalan 6 / 20 +10 XP

Hitung luas segi tiga yang berbucu A(0, 0), B(6, 2) dan C(2, 5).

Huraian: Luas = 0.5 |(0 + 30 + 0) - (0 + 4 + 0)| = 0.5(26) = 13 unit^2.

Soalan 7 / 20 +10 XP

Titik A(-1, 2), B(3, 5) dan C(7, k) membentuk segi tiga dengan luas 10 unit^2. Jika k > 8, cari nilai k.

Huraian: Kecerunan AB = 3/4 => garis AB melalui (7, 8). Jarak tegak pada x=7 memberi 0.5 * |[( -5 + 3k + 14) - (6 + 35 - k)]| = 0.5|4k - 32| = 10 => |4k - 32| = 20 => 4k = 52 => k = 13 (atau 4k = 12 => k = 3).

Soalan 8 / 20 +10 XP

Cari persamaan lokus titik bergerak P(x, y) yang sentiasa berjarak 5 unit dari titik tetap C(3, -1).

Huraian: (x - 3)^2 + (y + 1)^2 = 25 => x^2 - 6x + 9 + y^2 + 2y + 1 - 25 = 0 => x^2 + y^2 - 6x + 2y - 15 = 0.

Soalan 9 / 20 +10 XP

Titik P(x, y) bergerak supaya sentiasa sama jarak dari titik A(1, 3) dan B(5, 1). Cari persamaan lokus P.

Huraian: (x - 1)^2 + (y - 3)^2 = (x - 5)^2 + (y - 1)^2 => -2x - 6y + 10 = -10x - 2y + 26 => 8x - 4y - 16 = 0 => 2x - y - 4 = 0.

Soalan 10 / 20 +10 XP

Garis lurus L1 melalui (2, 5) dan selari dengan garis 3x - y + 4 = 0. Cari pintasan-y bagi L1.

Huraian: Kecerunan ialah 3. Ganti (2, 5) ke y = 3x + c: 5 = 6 + c => c = -1.

Soalan 11 / 20 +10 XP

Diberi A(2, 1), B(6, 5) dan titik P pada tembereng AB memenuhi 4AP = AB. Cari koordinat P.

Huraian: AP : PB = 1 : 3. x = [3(2) + 1(6)]/4 = 3; y = [3(1) + 1(5)]/4 = 2. Maka P(3, 2).

Soalan 12 / 20 +10 XP

Cari jarak terdekat daripada titik P(4, 1) ke garis lurus 3x + 4y = 6 melalui kaki serenjang Q pada garis tersebut.

Huraian: Garis serenjang melalui P(4, 1) ialah 4x - 3y = 13. Persilangan dengan 3x + 4y = 6 ialah Q(2.8, -0.6). Jarak PQ = punca((4 - 2.8)^2 + (1 - (-0.6))^2) = punca(1.44 + 2.56) = 2 unit.

Soalan 13 / 20 +10 XP

Suatu sisi empat mempunyai bucu berturutan P(0, 0), Q(4, 0), R(5, 3) dan S(1, 3). Cari luas sisi empat ini.

Huraian: Segi empat selari dengan tapak PQ = 4 dan tinggi = 3, maka luas = 4 * 3 = 12 unit^2.

Soalan 14 / 20 +10 XP

Titik (0, 2) membahagikan tembereng yang menyambungkan A(-4, 0) dan B(h, k) dalam nisbah 1 : 2. Cari koordinat B.

Huraian: (2(-4) + 1(h))/3 = 0 => h = 8; (2(0) + 1(k))/3 = 2 => k = 6. Maka B(8, 6).

Soalan 15 / 20 +10 XP

Soalan 16 / 20 +10 XP

Tentukan pintasan-x bagi garis lurus yang melalui (3, 4) dan berserenjang dengan garis y = -x/2 + 5.

Huraian: Kecerunan serenjang m = 2. y - 4 = 2(x - 3) => y = 2x - 2. Pada y = 0: 2x = 2 => x = 1.

Soalan 17 / 20 +10 XP

Jika tiga bucu sebuah segi empat selari ABCD mengikut turutan ialah A(1, 1), B(5, 2) dan C(6, 5), cari koordinat bucu D.

Huraian: Titik tengah AC = titik tengah BD: ((1+6)/2, (1+5)/2) = ((5+x)/2, (2+y)/2) => x = 2, y = 4.

Soalan 18 / 20 +10 XP

Garis lurus kx - 3y = 6 dan 4x + 2y = 5 adalah selari. Cari nilai k.

Huraian: m1 = k/3 dan m2 = -4/2 = -2. Selari => k/3 = -2 => k = -6.

Soalan 19 / 20 +10 XP

Cari koordinat titik pada paksi-x yang sama jarak dari titik P(1, 3) dan Q(5, 5).

Huraian: Titik (x, 0): (x - 1)^2 + 9 = (x - 5)^2 + 25 => -2x + 10 = -10x + 50 => 8x = 40 => x = 5.

Soalan 20 / 20 +10 XP

Lokus titik bergerak P membentuk bulatan x^2 + y^2 - 8x + 6y = 0. Cari jarak antara pusat bulatan itu dengan asalan (0, 0).

Huraian: (x - 4)^2 + (y + 3)^2 = 25. Pusat ialah (4, -3), jarak dari (0, 0) ialah punca(4^2 + (-3)^2) = 5 unit.
