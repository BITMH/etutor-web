Bab 1: Fungsi dan Persamaan Kuadratik dalam Satu Pemboleh Ubah

Menguasai ciri ungkapan dan fungsi kuadratik f(x) = ax² + bx + c (a ≠ 0), kesan perubahan nilai a, b dan c pada lengkung parabola, paksi simetri, titik maksimum/minimum, kaedah pemfaktoran punca dan lakaran graf serta masalah SPM.
Rujukan Rasmi: SK 1.1 (DSKP KSSM Matematik Tingkatan 4)

Nota Ringkas Matematik Tingkatan 4 • Sedia untuk cetakan atau simpanan PDF.

Objektif Pembelajaran DSKP

Sasaran Penguasaan Bab Ini

  1. Mengenal pasti ungkapan kuadratik dalam satu pemboleh ubah (kuasa tertinggi tepat 2, bukan punca kuasa atau indeks negatif).
  2. Menjelaskan kesan perubahan pekali a (bentuk ∪ atau ∩ dan kelebaran lengkung), b (kedudukan paksi simetri x = -b/(2a)) dan c (pintasan-y) terhadap graf fungsi kuadratik.
  3. Menentukan punca persamaan kuadratik ax² + bx + c = 0 menggunakan kaedah pemfaktoran dan kaedah graf (pintasan-x).
  4. Melakar graf fungsi kuadratik serta menyelesaikan masalah harian melibatkan luas, perimeter atau panjang dalam bentuk persamaan kuadratik.
Nota Ringkas & Contoh Terkawal (m.s. 1–32)

Ringkasan Teras Mengikut Subtopik

1.1 Ungkapan & Fungsi Kuadratik dalam Satu Pemboleh Ubah (m.s. 3–10)

Ungkapan kuadratik dalam satu pemboleh ubah mempunyai bentuk am ax² + bx + c dengan a, b, c ialah pemalar dan a ≠ 0. Hanya SATU jenis pemboleh ubah wujud dengan kuasa tertinggi tepat 2.

  • Contoh SAH: x² - 5 (a=1, b=0, c=-5), -(1/2)y² + 3y. Contoh BUKAN kuadratik: 2x² + x⁻² (ada kuasa -2), 3y² - 3x + 1 (ada dua pemboleh ubah y & x), x³ - 2x (kuasa tertinggi 3).
  • Fungsi kuadratik f(x) = ax² + bx + c ialah hubungan BANYAK KEPADA SATU (garisan mengufuk memotong graf pada dua titik berbeza).
  • Bentuk graf parabola: Jika a > 0, graf berbentuk ∪ (senyum) dan mempunyai satu TITIK MINIMUM; jika a < 0, graf berbentuk ∩ (masam) dan mempunyai satu TITIK MAKSIMUM.

Contoh Terkawal: Tentukan sama ada g(x) = 3x - 2x² + 7 ialah fungsi kuadratik dan nyatakan nilai a, b, c serta titik ekstremnya (maksimum atau minimum).

Penyelesaian: Susun semula: g(x) = -2x² + 3x + 7. Ya, fungsi kuadratik satu pemboleh ubah dengan a = -2, b = 3, c = 7. Kerana a < 0, graf berbentuk ∩ dan mempunyai titik MAKSIMUM.

Tip Penting: Berhati-hati apabila sebutan disusun tidak mengikut tertib! Nilai 'a' sentiasa pekali bagi x², bukan nombor yang ditulis paling hadapan!

1.2 Kesan Perubahan Nilai a, b dan c pada Graf (m.s. 12–15)

Setiap pemalar dalam f(x) = ax² + bx + c mengawal ciri geometri lengkung parabola secara bebas dan boleh diuji melalui lakaran perbandingan graf.

  • Nilai |a| mengawal KELEBARAN graf: semakin besar |a|, semakin SEMPIT/mencuram bukaan lengkung parabola (graf lebih kurus menghampiri paksi-y); semakin kecil |a|, semakin lebar.
  • Nilai b bersama a menentukan kedudukan paksi simetri x = -b / (2a): jika a dan b bertanda SAMA, paksi simetri berada di sebelah KIRI paksi-y (x < 0); jika bertanda BERBEZA, di sebelah KANAN (x > 0); jika b = 0, paksi simetri tepat pada paksi-y (x = 0).
  • Nilai c ialah PINTASAN-y iaitu koordinat (0, c) tempat graf memotong paksi menegak.

Contoh Terkawal: Diberi f(x) = x² - 6x + 5. Cari persamaan paksi simetri, koordinat titik minimum dan pintasan-y.

Penyelesaian: a=1, b=-6, c=5. Paksi simetri: x = -(-6)/(2×1) = 3. Ganti x=3: f(3) = 3² - 6(3) + 5 = -4. Titik minimum ialah (3, -4) dan pintasan-y ialah 5.

Tip Penting: Rumus pantas titik pusingan: cari x = -b/(2a) dahulu, atau ambil purata dua punca x = (x₁ + x₂)/2!

1.3 Menentukan Punca dengan Kaedah Pemfaktoran & Graf (m.s. 16–24)

Punca bagi persamaan kuadratik ax² + bx + c = 0 ialah nilai pemboleh ubah x yang memuaskan persamaan itu, yang secara geometrinya merupakan PINTASAN-x (tempat graf f(x) memotong paksi mengufuk).

  • Langkah Wajib sebelum memfaktorkan: Susun persamaan kepada BENTUK AM ax² + bx + c = 0 (sebelah kanan MESTI sifar!). Contoh: 3x² - 7x + 5 = 3 → 3x² - 7x + 2 = 0.
  • Faktorkan menjadi (px + r)(qx + s) = 0, kemudian selesaikan px + r = 0 atau qx + s = 0.
  • Jika graf f(x) tidak bersilang dengan paksi-x (cth f(x) = x² + 1 sentiasa di atas paksi-x), persamaan kuadratik tidak mempunyai punca nyata.

Contoh Terkawal: Selesaikan persamaan kuadratik 2x² = 9 - 3x menggunakan kaedah pemfaktoran.

Penyelesaian: Bentuk am: 2x² + 3x - 9 = 0 → (2x - 3)(x + 3) = 0 → x = 3/2 atau x = -3.

Tip Penting: JANGAN lupa bahagikan kedua-dua belah dengan faktor atau tukar ke bentuk am (= 0) sebelum memfaktorkan!

1.4 Melakar Graf & Masalah Harian Kuadratik (m.s. 25–30)

Lakaran graf kuadratik lengkap dan aplikasi geometri segi empat tepat (luas padang, taman bunga atau rangka kuboid seperti Contoh 10) kerap menjadi soalan berstruktur SPM.

  • Empat ciri wajib pada lakaran graf kuadratik: (1) Bentuk ∪ (a>0) atau ∩ (a<0); (2) Pintasan-y pada (0, c); (3) Punca/pintasan-x jika bersilang; (4) Titik maksimum/minimum & paksi simetri.
  • Dalam masalah geometri: tulis ungkapan luas/perimeter dalam sebutan x (contoh Luas = x(5x + 20)), samakan dengan luas diberi, susun menjadi ax² + bx + c = 0 dan faktorkan.
  • TOLAK nilai x negatif apabila x mewakili panjang fizikal, umur atau bilangan objek nyata (cth panjang = x > 0)!

Contoh Terkawal: Sebuah padang segi empat tepat mempunyai panjang (5x + 20) m dan lebar x m. Jika luasnya ialah 160 m², cari nilai x.

Penyelesaian: Luas = x(5x + 20) = 160 → 5x² + 20x - 160 = 0. Bahagi 5: x² + 4x - 32 = 0 → (x + 8)(x - 4) = 0 → x = 4 (tolak x = -8 kerana lebar tidak boleh negatif).

Tip Penting: Sentiasa permudahkan persamaan kuadratik dengan membahagi FSTB (seperti ÷5) supaya nombor lebih mudah difaktorkan!

Amaran Pemeriksa

3 Kesilapan Lazim & Tip Skor Exam

Kesilapan Lazim: Menganggap x(x - 3) = 4 bermakna x = 4 atau x - 3 = 4.

Pembetulan Tepat: Sifat hasil darab sifar hanya sah apabila sebelah kanan ialah SIFAR (= 0)! Kembangkan dahulu menjadi x² - 3x - 4 = 0 → (x - 4)(x + 1) = 0.

Tip Skor Exam: Bentuk am WAJIB '= 0' sebelum menulis faktor berasingan!

Kesilapan Lazim: Menulis kedua-dua punca x = 4 dan x = -8 sebagai jawapan panjang atau lebar sisi tanah.

Pembetulan Tepat: Nyatakan secara jelas bahawa punca negatif ditolak kerana ukuran panjang atau jarak tidak mungkin negatif.

Tip Skor Exam: Sentiasa tulis catatan 'Oleh kerana x > 0, maka x = 4' pada baris akhir masalah harian.

Kesilapan Lazim: Mengelirukan kesan nilai |a| terhadap lebar parabola: menyangka |a| besar bermaksud graf lebih lebar.

Pembetulan Tepat: Semakin besar |a| (seperti y = 4x² berbanding y = ½x²), nilai y naik lebih cepat → graf lebih SEMPIT (kurus).

Tip Skor Exam: Uji x = 1: y = 4(1)² = 4 (tinggi/sempit) vs y = ½(1)² = 0.5 (rendah/lebar)!

Soalan 1 / 20 +10 XP

Antara berikut, ungkapan manakah merupakan ungkapan kuadratik dalam satu pemboleh ubah?

Huraian: '-1/2 x² + 4' hanya ada satu pemboleh ubah x dengan kuasa tertinggi tepat 2 (a = -1/2 ≠ 0, b = 0, c = 4).

Soalan 2 / 20 +10 XP

Bagi fungsi kuadratik f(x) = 7 + 8x - x², tentukan koordinat titik maksimumnya.

Huraian: a = -1, b = 8, c = 7. Paksi simetri x = -8/(2×-1) = 4. f(4) = 7 + 8(4) - 4² = 7 + 32 - 16 = 23 → (4, 23).

Soalan 3 / 20 +10 XP

Diberi persamaan 3x² - 5x - 2 = 0. Tentukan punca-puncanya.

Huraian: (3x + 1)(x - 2) = 0 → 3x + 1 = 0 (x = -1/3) atau x - 2 = 0 (x = 2).

Soalan 4 / 20 +10 XP

Graf fungsi kuadratik manakah yang paling SEMPIT bukaannya dan terbuka ke BAWAH (bentuk ∩)?

Huraian: Terbuka ke bawah memerlukan a < 0, dan paling sempit memerlukan nilai mutlak |a| paling besar → a = -5.

Soalan 5 / 20 +10 XP

Fungsi kuadratik y = x² + bx + 6 mempunyai paksi simetri x = 3. Apakah nilai pemalar b?

Huraian: x = -b/(2a) → 3 = -b/(2×1) → b = -6.

Soalan 6 / 20 +10 XP

Cari punca positif bagi persamaan 2x² + 8x = 24.

Huraian: 2x² + 8x - 24 = 0 → bahagi 2: x² + 4x - 12 = 0 → (x + 6)(x - 2) = 0 → x = 2 (atau -6).

Soalan 7 / 20 +10 XP

Sebuah graf kuadratik f(x) = ax² + bx + c memotong paksi-x pada x = -2 dan x = 6. Apakah persamaan paksi simetrinya?

Huraian: Paksi simetri berada tepat di tengah-tengah dua punca: x = (-2 + 6)/2 = 4/2 = 2.

Soalan 8 / 20 +10 XP

Apakah hubungan jenis graf bagi mana-mana fungsi kuadratik f(x) = ax² + bx + c?

Huraian: Dua nilai x yang simetri memetakan ke satu nilai f(x) yang sama, maka fungsi kuadratik ialah hubungan banyak kepada satu.

Soalan 9 / 20 +10 XP

Jika suatu persamaan kuadratik mempunyai punca x = 3 dan x = -1 dengan pekali x² = 1, nyatakan persamaan itu dalam bentuk am.

Huraian: (x - 3)(x + 1) = 0 → x² + x - 3x - 3 = 0 → x² - 2x - 3 = 0.

Soalan 10 / 20 +10 XP

Manakah daripada nilai x berikut merupakan punca bagi 3x² - 7x + 5 = 3?

Huraian: Tukarkan ke bentuk am: 3x² - 7x + 2 = 0 → (3x - 2)(x - 1) = 0 → x = 2/3 atau x = 1.

Soalan 11 / 20 +10 XP

Diberi fungsi kuadratik g(x) = 9 - 4x - 3x². Nyatakan nilai bagi pekali a, b dan c.

Huraian: Susun dalam bentuk am ax² + bx + c: g(x) = -3x² - 4x + 9, maka a = -3, b = -4 dan c = 9.

Soalan 12 / 20 +10 XP

Bagi fungsi kuadratik f(x) = ax² + bx + c dengan keadaan a < 0 dan b < 0, di manakah kedudukan paksi simetrinya?

Huraian: Paksi simetri x = -b/(2a). Apabila a dan b bertanda sama (kedua-duanya negatif), hasil bahagi b/a adalah positif, maka -b/(2a) < 0 (di sebelah kiri paksi-y).

Soalan 13 / 20 +10 XP

Apakah koordinat titik minimum dan pintasan-y bagi graf fungsi f(x) = 2x² - 8?

Huraian: Kerana b = 0, paksi simetri ialah x = 0. Apabila x = 0, f(0) = -8, maka titik minimum ialah (0, -8) dan pintasan-y ialah -8.

Soalan 14 / 20 +10 XP

Cari koordinat pintasan-x bagi graf fungsi kuadratik f(x) = x² - 5x - 14.

Huraian: Pada paksi-x, f(x) = 0: x² - 5x - 14 = 0 -> (x - 7)(x + 2) = 0 -> x = 7 atau x = -2, iaitu (7, 0) dan (-2, 0).

Soalan 15 / 20 +10 XP

Sebuah kadbod segi empat tepat mempunyai panjang (2x + 3) cm dan lebar x cm. Jika luas kadbod itu ialah 44 cm², cari nilai x.

Huraian: x(2x + 3) = 44 -> 2x² + 3x - 44 = 0 -> (2x + 11)(x - 4) = 0. Oleh sebab panjang/lebar x > 0, maka x = 4 cm.

Soalan 16 / 20 +10 XP

Selesaikan persamaan kuadratik x(x - 3) = 10.

Huraian: Kembangkan kepada bentuk am (= 0): x² - 3x - 10 = 0 -> (x - 5)(x + 2) = 0 -> x = 5 atau x = -2.

Soalan 17 / 20 +10 XP

Graf f(x) = x² - 2x + 3 digerakkan ke bawah sebanyak 5 unit secara menegak. Apakah persamaan fungsi baharu itu dan pintasan-y baharunya?

Huraian: Anjakan menegak ke bawah sebanyak 5 unit mengurangkan nilai c sebanyak 5: 3 - 5 = -2, maka g(x) = x² - 2x - 2 dengan pintasan-y = -2.

Soalan 18 / 20 +10 XP

Graf fungsi kuadratik manakah yang TIDAK bersilang dengan paksi-x?

Huraian: Bagi f(x) = x² + 4, a = 1 > 0 (terbuka ke atas) dengan titik minimum (0, 4) di atas paksi-x, maka graf tidak memotong paksi-x (tiada punca nyata).

Soalan 19 / 20 +10 XP

Diberi x = -2 ialah satu daripada punca bagi persamaan kuadratik 2x² + kx - 6 = 0. Hitung nilai k.

Huraian: Gantikan x = -2: 2(-2)² + k(-2) - 6 = 0 -> 8 - 2k - 6 = 0 -> 2k = 2 -> k = 1.

Soalan 20 / 20 +10 XP

Hasil darab dua integer positif berturutan ialah 72. Jika integer yang lebih kecil ialah n, persamaan kuadratik manakah yang mewakili situasi ini dan apakah nilai n?

Huraian: n(n + 1) = 72 -> n² + n - 72 = 0 -> (n + 9)(n - 8) = 0. Kerana n ialah integer positif, n = 8 (integer berturutan ialah 8 dan 9).
