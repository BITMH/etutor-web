SUBTOPIK 01

7.1 Jasad Hitam, Kuanta Tenaga Max Planck & Foton (SK 7.1)

Percanggahan ramalan teori klasik dengan spektrum eksperimen jasad hitam pada frekuensi tinggi (bencana ultraungu) melahirkan konsep kuantum tenaga diskrit oleh Max Planck.

  • Jasad hitam unggul menyerap 100% sinaran tuju; graf keamatan melawan panjang gelombang memuncak lebih tinggi dan bergeser ke panjang gelombang lebih pendek apabila suhu meningkat.
  • Tokoh kuantum: Max Planck (kuantum tenaga diskrit), Albert Einstein (foton & kesan fotoelektrik), Niels Bohr (spektrum garis diskrit atom hidrogen) dan Louis de Broglie (kedualan gelombang-zarah).
  • Tenaga satu foton: E = h f = (h c) / lambda, dengan h = 6.63 x 10^-34 J s dan c = 3.00 x 10^8 m s^-1. Tukarkan nm kepada meter (x 10^-9) sebelum mengira.

Contoh: Satu sumber cahaya ultraungu memancarkan foton dengan panjang gelombang 300 nm. Hitungkan tenaga bagi satu foton tersebut dalam unit Joule dan eV (1 eV = 1.60 x 10^-19 J).

Penyelesaian: E = (6.63 x 10^-34 x 3.00 x 10^8) / (300 x 10^-9) = 6.63 x 10^-19 J. Dalam eV: 6.63e-19 / 1.60e-19 = 4.14 eV.

Tip Penting: Kuantum tenaga ialah paket tenaga diskrit yang berkadar terus dengan frekuensi f dan berkadar songsang dengan panjang gelombang lambda.

SUBTOPIK 02

7.2 Kedualan Gelombang-Zarah de Broglie & Kuasa Foton (SK 7.1)

Semua zarah subatom seperti elektron menunjukkan sifat gelombang dengan panjang gelombang de Broglie lambda = h / (mv), manakala alur foton mempunyai kuasa pancaran P = nhf.

  • Rumus panjang gelombang de Broglie: lambda = h / p = h / (m v). Corak cincin pembelauan alur elektron melalui lapisan grafit nipis membuktikan elektron bersifat gelombang.
  • Mikroskop elektron mempunyai panjang gelombang alur elektron 1 000–10 000 kali lebih pendek daripada cahaya tampak (400–750 nm), meminimumkan kesan pembelauan untuk menghasilkan kuasa pembezaan (resolusi) amat tinggi.
  • Kuasa foton P = n h f = (n h c) / lambda, dengan n ialah BILANGAN FOTON YANG DIPANCARKAN SESAAT (unit s^-1). Jika lampu mempunyai kecekapan cahaya 10%, gunakan P_cahaya = 0.10 x P_elektrik.

Contoh: Sebatang pen laser merah memancarkan cahaya berpanjang gelombang 670 nm pada kadar 3.37 x 10^18 foton sesaat. Hitungkan kuasa output laser tersebut.

Penyelesaian: P = n h c / lambda = (3.37e18 x 6.63e-34 x 3.00e8) / (670e-9) = 0.6703 / 6.70e-7 = 1.00 W.

Tip Penting: Pastikan huruf n dalam P = nhf ialah kadar bilangan foton per saat, bukan jumlah foton dalam beberapa minit.

SUBTOPIK 03

7.3 Kesan Fotoelektrik, 4 Ciri Eksperimen & Kit LED (SK 7.2)

Kesan fotoelektrik membebaskan fotoelektron daripada permukaan logam secara serta-merta apabila disinari foton berfrekuensi mencapai atau melebihi frekuensi ambang f0.

  • 4 Ciri Kesan Fotoelektrik: (1) K_maks bergantung pada frekuensi f (bukan keamatan); (2) Wujud frekuensi ambang f0 minimum bagi setiap logam; (3) Keamatan cahaya bertambah meningkatkan arus fotoelektrik (bilangan fotoelektron sesaat) apabila f >= f0; (4) Pemancaran berlaku serta-merta tanpa masa lengah.
  • Berbeza daripada pancaran termion yang memerlukan pemanasan lama logam, kesan fotoelektrik berlaku serta-merta kerana satu foton memindahkan keseluruhan tenaganya kepada satu elektron.
  • Aktiviti 7.5 Kit LED: memplot voltan pengaktifan Va melawan 1/lambda bagi LED berlainan warna memberi garis lurus berkecerunan m = h c / e, maka pemalar Planck eksperimen ialah h = (m e) / c.

Contoh: Dalam Aktiviti 7.5 menggunakan kit LED, kecerunan graf Va melawan 1/lambda ialah 1.243 x 10^-6 V m. Hitungkan nilai pemalar Planck h (e = 1.60 x 10^-19 C, c = 3.00 x 10^8 m s^-1).

Penyelesaian: h = (m e) / c = (1.243 x 10^-6 x 1.60 x 10^-19) / (3.00 x 10^8) = 6.63 x 10^-34 J s.

Tip Penting: Jangan kelirukan peranan frekuensi f (mengawal K_maks setiap elektron) dengan keamatan cahaya (mengawal bilangan elektron sesaat / arus).

SUBTOPIK 04

7.4 Persamaan Fotoelektrik Einstein & Aplikasi (SK 7.3)

Persamaan Einstein hf = W + K_maks menjelaskan pengagihan tenaga foton kepada fungsi kerja logam W dan tenaga kinetik maksimum fotoelektron, mendasari sel suria serta pengesan automatik.

  • Fungsi kerja W = h f0 = h c / lambda_0 ialah tenaga minimum untuk membebaskan fotoelektron dari permukaan logam. Syarat kesan fotoelektrik berlaku: f >= f0 atau lambda <= lambda_0.
  • Persamaan Einstein: h f = W + 1/2 m v_maks^2 = h f0 + K_maks. Pada graf K_maks melawan f: garis lurus selari bagi semua logam dengan kecerunan m = h, pintasan paksi-f = frekuensi ambang f0, dan pintasan paksi-y (ekstrapolasi) = -W.
  • Aplikasi: sel suria (lampu jalan LED, loji kuasa suria, panel ISS) menukar cahaya kepada elektrik; pintu automatik menggunakan gangguan alur inframerah ke sel foto yang memutuskan arus fotoelektrik lalu membuka pintu.

Contoh: Cahaya monokromatik (lambda = 550 nm) disinarkan ke atas logam berfungsi kerja W = 2.00 eV. Hitungkan tenaga kinetik maksimum (dalam J) dan halaju maksimum fotoelektron (m_e = 9.11 x 10^-31 kg).

Penyelesaian: E = (6.63e-34 x 3.00e8) / 550e-9 = 3.616 x 10^-19 J. W = 2.00 x 1.60e-19 = 3.20 x 10^-19 J. K_maks = 3.616e-19 - 3.20e-19 = 4.16 x 10^-20 J. v_maks = sqrt(2 x 4.16e-20 / 9.11e-31) = 3.02 x 10^5 m s^-1.

Tip Penting: Apabila graf K_maks melawan f diberi dalam unit eV, darabkan nilai eV dengan 1.60 x 10^-19 J sebelum mengira kecerunan h dalam J s.

AMARAN PEMERIKSA #1

ELAKKAN: Menyangka keamatan cahaya yang lebih tinggi meningkatkan tenaga kinetik maksimum atau membolehkan kesan fotoelektrik berlaku di bawah frekuensi ambang f0.

TEPAT: Tenaga setiap foton hanya bergantung pada frekuensi (E = hf). Keamatan hanya menentukan bilangan foton sesaat (arus fotoelektrik); jika f < f0, tiada fotoelektron terpancar walau seterang mana cahaya.

Tip Skor Exam: Ingat: Frekuensi f -> Tenaga kinetik K_maks; Keamatan -> Bilangan fotoelektron (Arus).

AMARAN PEMERIKSA #2

ELAKKAN: Membandingkan panjang gelombang cahaya dengan panjang gelombang ambang secara terbalik (menyangka lambda > lambda_0 menghasilkan kesan fotoelektrik).

TEPAT: Oleh sebab tenaga foton berkadar songsang dengan panjang gelombang, syarat tenaga E >= W memerlukan lambda cahaya tuju MESTILAH LEBIH PENDEK atau sama dengan panjang gelombang ambang (lambda <= lambda_0).

Tip Skor Exam: Sentiasa tulis syarat f >= f0 atau lambda <= lambda_0 sebelum menyemak pemancaran fotoelektron.

AMARAN PEMERIKSA #3

ELAKKAN: Terlupa menukar unit fungsi kerja W daripada elektronvolt (eV) kepada Joule (J) sebelum menggunakan rumus hf = W + 1/2 mv^2.

TEPAT: 1 eV = 1.60 x 10^-19 J. Semua tenaga dalam rumus v_maks = sqrt(2 K_maks / m) dan nilai h dalam J s mesti berada dalam unit Joule.

Tip Skor Exam: Tukar nilai eV kepada Joule serta-merta di langkah pertama pengiraan halaju fotoelektron.

Soalan 11 / 20 +10 XP

Fungsi kerja logam natrium ialah 2.28 eV. Hitungkan panjang gelombang ambang lambda_0 bagi natrium (h = 6.63 x 10^-34 J s, c = 3.00 x 10^8 m s^-1, 1 eV = 1.60 x 10^-19 J).

Huraian: W = 2.28 x 1.60e-19 = 3.648e-19 J. lambda_0 = hc / W = (6.63e-34 x 3.00e8) / 3.648e-19 = 5.45 x 10^-7 m = 545 nm.

Merujuk logam natrium pada soalan sebelumnya (lambda_0 = 545 nm), apakah yang berlaku apabila cahaya merah berpanjang gelombang 680 nm disinarkan ke atas natrium itu?

Huraian: Kerana 680 nm > 545 nm, tenaga foton cahaya merah lebih kecil daripada fungsi kerja natrium (f < f0), jadi kesan fotoelektrik tidak berlaku.

Soalan 13 / 20 +10 XP

Graf tenaga kinetik maksimum K_maks melawan frekuensi f diplot untuk dua logam P dan Q yang berbeza (dengan f0_Q > f0_P). Pernyataan manakah yang BETUL?

Huraian: Kecerunan bagi semua logam ialah pemalar Planck h yang sama (garis selari), manakala f0 lebih tinggi bagi Q bererti W_Q = hf0_Q > W_P.

Soalan 14 / 20 +10 XP

Frekuensi ambang bagi logam Cesium ialah 5.16 x 10^14 Hz. Hitungkan fungsi kerja logam Cesium dalam unit eV.

Huraian: W = h f0 = 6.63e-34 x 5.16e14 = 3.421e-19 J = 3.421e-19 / 1.60e-19 = 2.14 eV.

Soalan 15 / 20 +10 XP

Apabila cahaya berfrekuensi 8.0 x 10^14 Hz menyinari permukaan logam dengan frekuensi ambang 5.0 x 10^14 Hz, hitungkan tenaga kinetik maksimum fotoelektron yang terpancar.

Huraian: K_maks = h(f - f0) = 6.63e-34 x (8.0e14 - 5.0e14) = 6.63e-34 x 3.0e14 = 1.989 x 10^-19 J (1.99 x 10^-19 J).

Soalan 16 / 20 +10 XP

Sebuah fotodiod disinari cahaya merah (lambda_1 = 700 nm) dan kemudian cahaya biru (lambda_2 = 400 nm). Tenaga kinetik maksimum fotoelektron oleh cahaya biru adalah 2 kali ganda daripada cahaya merah. Berapakah fungsi kerja W bahan fotodiod itu?

Huraian: E1 = 2.84e-19 J = W + K1; E2 = 4.97e-19 J = W + 2K1. Daripada 2(E1) - E2 = W => W = 2(2.84e-19) - 4.97e-19 = 7.10 x 10^-20 J.

Soalan 17 / 20 +10 XP

Apakah perbezaan prinsip antara kesan fotoelektrik dengan pancaran termion?

Huraian: Kesan fotoelektrik berlaku serta-merta apabila tenaga foton >= W pada suhu bilik, sedangkan pancaran termion memerlukan tenaga haba untuk memanaskan katod.

Soalan 18 / 20 +10 XP

Bagaimanakah sistem pintu automatik di pusat beli-belah berfungsi menggunakan sel foto?

Huraian: Halangan fizikal memutuskan alur inframerah ke sel foto, menghentikan arus fotoelektrik dan mencetuskan geganti membuka pintu secara automatik.

Soalan 19 / 20 +10 XP

Apakah komponen utama yang terdapat di atas sayap besar Stesen Angkasa Antarabangsa (ISS) bagi menjana 84 hingga 120 kW tenaga elektrik bersih?

Huraian: ISS menggunakan ribuan sel suria berasaskan kesan fotoelektrik untuk menjanakan tenaga elektrik secara langsung daripada sinaran Matahari.

Soalan 20 / 20 +10 XP

Sebutir zarah alfa bergerak dengan momentum 4 kali ganda momentum sebiji proton. Apakah nisbah panjang gelombang de Broglie zarah alfa kepada proton (lambda_alfa : lambda_proton)?

Huraian: Daripada lambda = h / p, panjang gelombang de Broglie berkadar songsang dengan momentum p. Jika p_alfa = 4 p_proton, maka lambda_alfa / lambda_proton = 1 / 4.
