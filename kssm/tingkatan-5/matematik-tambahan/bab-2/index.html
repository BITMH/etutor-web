SUBTOPIK 01

2.1 Had Fungsi dan Pembezaan Prinsip Pertama (SK 2.1)

Had f(x) apabila x → a ialah nilai sasaran yang dihampiri oleh fungsi itu. Terbitan pertama dy/dx pula ditakrifkan sebagai had nisbah δy/δx apabila tokokan δx menghampiri sifar.

  • Apabila penggantian terus x = a memberi bentuk tak tentu 0/0, selesaikan melalui pemfaktoran (memansuhkan faktor sepunya x − a) atau merasionalkan punca kuasa dengan ungkapan konjugat.
  • Rumus prinsip pertama: dy/dx = had (δx→0) [f(x + δx) − f(x)] / δx.
  • Empat langkah prinsip pertama: gantikan (x + δx), cari δy = f(x + δx) − f(x), bahagikan keseluruhan ungkapan dengan δx, dan ambil had apabila δx → 0.

Contoh: Nilaikan had (x→0) [√(x + 9) − 3] / x.

Penyelesaian: Penggantian terus x = 0 memberi 0/0. Darabkan pengangka dan penyebut dengan konjugat [√(x + 9) + 3]: [(x + 9) − 9] / [x(√(x + 9) + 3)] = x / [x(√(x + 9) + 3)] = 1 / (√(x + 9) + 3). Apabila x → 0, had = 1 / (3 + 3) = 1/6.

Tip Penting: Sentiasa kenali bentuk tak tentu 0/0 yang mengandungi punca kuasa dua sebagai isyarat untuk mendarab dengan konjugat!

SUBTOPIK 02

2.2 Pembezaan Peringkat Pertama dan Tiga Petua Utama (SK 2.2)

Fungsi algebra axⁿ dibezakan dengan rumus kuasa d/dx(axⁿ) = anxⁿ⁻¹. Ungkapan yang lebih kompleks menggunakan petua rantai, petua hasil darab atau petua hasil bahagi.

  • Tukarkan punca kuasa dan pecahan ringkas kepada bentuk indeks dahulu sebelum membeza, contohnya 3/x² = 3x⁻² dan √x = x^(1/2).
  • Petua rantai bagi fungsi gubahan y = uⁿ dengan u = g(x): dy/dx = (dy/du) × (du/dx) = n uⁿ⁻¹ × g'(x).
  • Petua hasil darab: d/dx(uv) = u(dv/dx) + v(du/dx); Petua hasil bahagi: d/dx(u/v) = [v(du/dx) − u(dv/dx)] / v².

Contoh: Bezakan y = (2x + 1) / (x − 3) terhadap x dan permudahkan jawapan anda.

Penyelesaian: Biarkan u = 2x + 1 (u' = 2) dan v = x − 3 (v' = 1). Menggunakan petua hasil bahagi: dy/dx = [(x − 3)(2) − (2x + 1)(1)] / (x − 3)² = (2x − 6 − 2x − 1) / (x − 3)² = −7 / (x − 3)².

Tip Penting: Dalam petua hasil bahagi, susunan pengangka wajib bermula dengan v(du/dx) tolak u(dv/dx), jangan sekali-kali diterbalikkan!

SUBTOPIK 03

2.3 Pembezaan Peringkat Kedua (SK 2.3)

Terbitan kedua d²y/dx² atau f''(x) diperoleh dengan membezakan terbitan pertama dy/dx terhadap x sekali lagi.

  • Tatatanda piawai terbitan kedua ialah d²y/dx² = d/dx(dy/dx) atau f''(x) = d/dx[f'(x)].
  • Dalam soalan indeks negatif seperti y = 4/x², nyatakan dy/dx = −8x⁻³ terlebih dahulu supaya mudah membezakannya sekali lagi kepada d²y/dx² = 24x⁻⁴ = 24/x⁴.
  • Terbitan kedua digunakan untuk menentukan kecekungan lengkung serta membezakan titik maksimum (d²y/dx² < 0) dan titik minimum (d²y/dx² > 0).

Contoh: Diberi f(x) = x³ − 3x² + 5x − 2. Cari nilai x yang memenuhi persamaan f''(x) = 12.

Penyelesaian: f'(x) = 3x² − 6x + 5, dan f''(x) = 6x − 6. Selesaikan 6x − 6 = 12 → 6x = 18 → x = 3.

Tip Penting: Bezakan fungsi dua kali berturut-turut dengan cermat sebelum menyamakan terbitan kedua dengan pemalar atau ungkapan lain.

SUBTOPIK 04

2.4 Aplikasi Pembezaan (SK 2.4)

Pembezaan diaplikasikan untuk mencari kecerunan dan persamaan tangen serta normal, menentukan titik pusingan dan nilai ekstrem, mengira kadar perubahan terhubung serta membuat penghampiran kecil.

  • Pada titik (x₁, y₁): kecerunan tangen m_t = dy/dx dan kecerunan normal m_n = −1 / m_t (kerana m_t × m_n = −1).
  • Pada titik pegun (dy/dx = 0): jika d²y/dx² < 0 ia titik maksimum; jika d²y/dx² > 0 ia titik minimum; jika d²y/dx² = 0, wajib uji tanda dy/dx di kiri dan kanan (jika tanda kekal sama, ia titik lengkok balas).
  • Kadar perubahan terhubung menggunakan dy/dt = (dy/dx) × (dx/dt), manakala perubahan hampir menggunakan δy ≈ (dy/dx) × δx.

Contoh: Menggunakan kaedah kalkulus, cari nilai hampir bagi √25.2.

Penyelesaian: Biarkan y = √x, maka dy/dx = 1/(2√x). Pilih x = 25 (y = 5) dan δx = 0.2. dy/dx pada x = 25 ialah 1/(2×5) = 0.1. Maka δy ≈ 0.1 × 0.2 = 0.02, dan √25.2 ≈ 5 + 0.02 = 5.02.

Tip Penting: Pilih nilai asal x sebagai nombor terdekat yang mudah dikira tanpa kalkulator, dan ambil δx = x_baharu − x_asal (berhati-hati dengan tanda negatif jika menyusut).

AMARAN PEMERIKSA #1

ELAKKAN: Tertinggal faktor terbitan dalaman (du/dx) semasa menggunakan petua rantai atau tertukar susunan tolakan dalam petua hasil bahagi.

TEPAT: Untuk y = (ax + b)ⁿ, sentiasa darab dengan pekali a; untuk u/v, pengangka sentiasa vu' − uv' (bukan uv' − vu').

Tip Skor Exam: Tulis u, u', v dan v' secara tersusun di tepi jalan kerja sebelum menggantikannya ke dalam rumus.

AMARAN PEMERIKSA #2

ELAKKAN: Menyimpulkan bahawa titik pegun ialah titik lengkok balas semata-mata tanpa menguji perubahan tanda dy/dx apabila d²y/dx² = 0.

TEPAT: Apabila d²y/dx² = 0, titik itu masih boleh menjadi titik maksimum atau minimum (contohnya y = x⁴ di x = 0). Ujian tanda dy/dx di kiri dan kanan wajib dilakukan.

Tip Skor Exam: Bina jadual tanda dy/dx pada x − 0.1, x dan x + 0.1 setiap kali mendapat d²y/dx² = 0.

AMARAN PEMERIKSA #3

ELAKKAN: Menggunakan tanda positif untuk kadar susutan atau δx apabila kuantiti berkurang.

TEPAT: Kuantiti yang berkurang atau bocor mempunyai kadar negatif (contoh: dV/dt = −4 cm³/s) dan tokokan δx yang negatif.

Tip Skor Exam: Perhatikan kata kunci seperti 'menyusut', 'mengurang' atau 'mengalir keluar' dan letakkan tanda negatif sejak langkah pertama.

Soalan 1 / 20 +10 XP

Nilaikan had (x→4) (x² − 16) / (x − 4).

Huraian: (x² − 16)/(x − 4) = (x + 4)(x − 4)/(x − 4) = x + 4. Apabila x → 4, had = 4 + 4 = 8.

Soalan 2 / 20 +10 XP

Cari nilai had (x→0) [√(x + 4) − 2] / x.

Huraian: Darab dengan konjugat [√(x + 4) + 2] memberi x / [x(√(x + 4) + 2)] = 1 / (√(x + 4) + 2). Pada x → 0, nilainya ialah 1 / (2 + 2) = 1/4.

Soalan 3 / 20 +10 XP

Jika y = 3x² − 5x + 1, apakah ungkapan δy / δx sebelum mengambil had δx → 0 melalui prinsip pertama?

Huraian: δy = 3(x + δx)² − 5(x + δx) + 1 − (3x² − 5x + 1) = (6x − 5)δx + 3(δx)². Membahagi dengan δx memberi 6x − 5 + 3δx.

Soalan 4 / 20 +10 XP

Diberi y = 4x³ − 6/x² + 7. Cari dy/dx.

Huraian: y = 4x³ − 6x⁻² + 7, maka dy/dx = 12x² − 6(−2)x⁻³ = 12x² + 12/x³.

Soalan 5 / 20 +10 XP

Bezakan y = (3x − 2)⁵ terhadap x.

Huraian: Menggunakan petua rantai: dy/dx = 5(3x − 2)⁴ × d/dx(3x − 2) = 5(3x − 2)⁴(3) = 15(3x − 2)⁴.

Soalan 6 / 20 +10 XP

Diberi y = √(2x² + 9). Cari nilai dy/dx apabila x = 2.

Huraian: dy/dx = ½(2x² + 9)^(-1/2) × 4x = 2x / √(2x² + 9). Pada x = 2, dy/dx = 2(2) / √(8 + 9) = 4/√17.

Soalan 7 / 20 +10 XP

Hitung nilai dy/dx bagi fungsi y = x(2x − 1)⁴ apabila x = 1.

Huraian: Dengan petua hasil darab: dy/dx = x[4(2x − 1)³(2)] + (2x − 1)⁴(1) = 8x(2x − 1)³ + (2x − 1)⁴. Pada x = 1, nilainya 8(1)(1) + 1 = 9.

Soalan 8 / 20 +10 XP

Diberi d/dx [(3x + 2) / (x − 1)] = k / (x − 1)². Apakah nilai pemalar k?

Huraian: Dengan petua hasil bahagi: [(x − 1)(3) − (3x + 2)(1)] / (x − 1)² = (3x − 3 − 3x − 2) / (x − 1)² = −5 / (x − 1)². Maka k = −5.

Soalan 9 / 20 +10 XP

Diberi f(x) = 2x³ − 5x² + 4x. Cari nilai x dengan keadaan f''(x) = 14.

Huraian: f'(x) = 6x² − 10x + 4, maka f''(x) = 12x − 10. Selesaikan 12x − 10 = 14 → 12x = 24 → x = 2.

Soalan 10 / 20 +10 XP

Jika y = x² + 3/x, hitung nilai d²y/dx² apabila x = −1.

Huraian: dy/dx = 2x − 3x⁻² dan d²y/dx² = 2 + 6x⁻³ = 2 + 6/x³. Pada x = −1, d²y/dx² = 2 + 6/(−1) = −4.

Soalan 11 / 20 +10 XP

Cari persamaan tangen kepada lengkung y = 2x³ − 4x + 1 pada titik x = 1.

Huraian: Pada x = 1, y = 2(1) − 4(1) + 1 = −1. dy/dx = 6x² − 4, maka m_t = 6(1) − 4 = 2. Persamaan tangen: y − (−1) = 2(x − 1) → y = 2x − 3.

Soalan 12 / 20 +10 XP

Cari persamaan normal kepada lengkung y = x² − 3x + 5 di titik (2, 3).

Huraian: dy/dx = 2x − 3. Pada x = 2, m_t = 2(2) − 3 = 1, maka kecerunan normal m_n = −1. Persamaan normal: y − 3 = −1(x − 2) → x + y = 5.

Soalan 13 / 20 +10 XP

Cari koordinat titik maksimum bagi lengkung y = x³ − 3x² − 9x + 4.

Huraian: dy/dx = 3x² − 6x − 9 = 3(x − 3)(x + 1) = 0 memberi x = −1 atau x = 3. d²y/dx² = 6x − 6; pada x = −1, d²y/dx² = −12 < 0 (maksimum) dan y = (−1) − 3 + 9 + 4 = 9.

Soalan 14 / 20 +10 XP

Bagi lengkung y = x⁴ − 4x³ + 1, apakah sifat titik pegun pada (0, 1)?

Huraian: dy/dx = 4x²(x − 3) = 0 di x = 0 dan d²y/dx² = 12x² − 24x = 0. Kerana dy/dx bernilai negatif pada x = −0.5 dan x = +0.5, tanda tidak berubah; maka (0, 1) ialah titik lengkok balas.

Soalan 15 / 20 +10 XP

Seutas wayar sepanjang 40 cm dibengkokkan membentuk sebuah segi empat tepat. Hitung luas maksimum yang boleh dibentuk oleh segi empat tepat itu.

Huraian: Jika panjang x dan lebar y, 2x + 2y = 40 → y = 20 − x. Luas A = 20x − x². dA/dx = 20 − 2x = 0 → x = 10, y = 10. Luas maksimum = 10 × 10 = 100 cm².

Soalan 16 / 20 +10 XP

Jejari sebuah belon sfera bertambah dengan kadar seragam 0.2 cm s⁻¹. Hitung kadar perubahan isi padu belon itu, dalam sebutan π, apabila jejarinya ialah 5 cm. [Isi padu sfera V = (4/3)πj³]

Huraian: dV/dj = 4πj². Menggunakan petua rantai, dV/dt = (dV/dj)(dj/dt) = 4π(5)²(0.2) = 100π(0.2) = 20π cm³ s⁻¹.

Soalan 17 / 20 +10 XP

Diberi y = 2x³ − 5x. Jika x bertambah daripada 2 kepada 2.01, cari perubahan hampir dalam y.

Huraian: dy/dx = 6x² − 5. Pada x = 2, dy/dx = 6(4) − 5 = 19. Dengan δx = 0.01, δy ≈ (dy/dx)δx = 19(0.01) = 0.19.

Soalan 18 / 20 +10 XP

Diberi y = 16 / x². Gunakan kaedah pembezaan untuk menganggarkan nilai bagi 16 / (2.02)².

Huraian: Pada x = 2, y = 4 dan dy/dx = −32/x³ = −4. Dengan δx = 0.02, δy ≈ (−4)(0.02) = −0.08. Nilai hampir = 4 − 0.08 = 3.92.

Soalan 19 / 20 +10 XP

Diberi y = 3x² + 4. Jika nilai x menyusut sebanyak 2% apabila x = 2, tentukan peratus perubahan hampir bagi y.

Huraian: Pada x = 2, y = 16, dy/dx = 6x = 12, dan δx = −0.02(2) = −0.04. δy ≈ 12(−0.04) = −0.48. Peratus perubahan y = (−0.48 / 16) × 100% = −3.0% (menyusut 3.0%).

Soalan 20 / 20 +10 XP

Lengkung y = ax² + bx melalui titik (1, 5) dan mempunyai satu titik pegun apabila x = 3. Cari nilai a dan b.

Huraian: Melalui (1, 5) memberi a + b = 5. Pada titik pegun x = 3, dy/dx = 2ax + b = 0 → 6a + b = 0 → b = −6a. Gantikan: a − 6a = 5 → a = −1 dan b = 6.
