SUBTOPIK 01

8.1 Enam Komponen Pemodelan Matematik & Soalan Terbuka

Model matematik mewakilkan situasi dunia sebenar menggunakan simbol, persamaan atau graf bagi meramalkan tingkah laku masa depan melalui enam komponen berkitar.

  • Enam komponen rasmi KSSM: (1) Mengenal pasti dan mendefinisikan masalah; (2) Membuat andaian dan mengenal pasti pemboleh ubah; (3) Mengaplikasi matematik untuk menyelesaikan masalah; (4) Menentusahkan dan mentafsir penyelesaian dalam konteks dunia sebenar; (5) Memurnikan model matematik (gelung berulang ke komponen 2 & 3); (6) Melaporkan dapatan.
  • Masalah berstruktur membekalkan semua parameter untuk satu jawapan tunggal, manakala soalan terbuka memerlukan penyelidik membuat andaian sendiri dan boleh menghasilkan lebih daripada satu model sah asalkan dapat dipertahankan dan ditentusahkan.
  • Contoh aplikasi di Malaysia termasuk sistem pengawalan banjir Terowong SMART Kuala Lumpur, ramalan lengkuk wabak COVID-19 serta perbandingan harga barang merentasi jarak perjalanan.

Contoh: Dalam kajian kes membeli 2 kampit beras 10 kg (Pasar Raya A = RM25.95, Pasar Raya B = RM23.99, jarak pergi sahaja s = 6 km, kecekapan kereta m = 17.6 km/L, petrol H = RM2.08/L), tentukan penjimatan bersih dan jarak maksimum berbaloi.

Penyelesaian: Beza harga S = (25.95 - 23.99) x 2 = RM3.92. Kos petrol 2 hala T = (6/17.6) x 2.08 x 2 = RM1.42 -> Penjimatan bersih = RM3.92 - RM1.42 = RM2.50. Had berbaloi S > T memberi s < 3.92 / (4.16/17.6) ≈ 16.6 km.

Tip Penting: Sentiasa darab 2 pada jarak pergi bagi perjalanan dua hala (pergi dan balik), serta semak kelemahan seperti nilai masa dan pelepasan CO2!

SUBTOPIK 02

8.2 Pemodelan Fungsi Linear & Kuadratik

Fungsi linear y = mx + c sesuai apabila kadar perubahan adalah malar, manakala fungsi kuadratik y = ax^2 + bx + c memodelkan lengkung parabola seperti keratan rentas sungai, kabel jambatan dan jarak berhenti.

  • Dalam fungsi linear (contoh suhu Gunung Kinabalu T(x) = -0.0065x + 30), kecerunan (-0.0065 darjah C/m) ialah kadar perubahan unit per unit dan pintasan-y (30 darjah C) ialah nilai awal pada x = 0.
  • Untuk menerbitkan model kuadratik y = ax^2 + bx + c daripada data jadual, gantikan tiga titik tak segaris (utamakan pintasan (0, c) jika ada untuk mendapat c serta-merta) dan selesaikan secara serentak.
  • Jarak berhenti kereta menggabungkan jarak reaksi linear dan jarak brek kuadratik: d(v) = av^2 + bv. Pada jalan basah, hanya pekali jarak brek a bertambah akibat geseran berkurang.

Contoh: Profil kedalaman sungai dimodelkan oleh y = -0.0136x^2 + 0.408x dengan x jarak dari tebing (0 <= x <= 30 m). Hitung anggaran kedalaman pada x = 10 m dan kedalaman maksimum di tengah sungai (x = 15 m).

Penyelesaian: Pada x = 10 m: y = -0.0136(100) + 0.408(10) = -1.36 + 4.08 = 2.72 m. Pada x = 15 m: y = -0.0136(225) + 0.408(15) = -3.06 + 6.12 = 3.06 m.

Tip Penting: Jika andaian sungai paling dalam di tengah tidak tepat bagi sungai sebenar, model perlu dimurnikan menggunakan lebih banyak titik ukuran!

SUBTOPIK 03

8.3 Pemodelan Fungsi Eksponen, Salingan & Domain Munasabah

Fungsi eksponen y = Ca^x memodelkan pertumbuhan mendadak (a > 1, seperti faedah kompaun dan maraton) atau susutan mendadak (0 < a < 1, seperti penyejukan). Setiap model terikat dengan domain yang munasabah.

  • Faedah kompaun tahunan A(t) = P(1 + r)^t dimurnikan apabila dikompaun n kali setahun kepada A(t) = P(1 + r/n)^(nt) (cth. bulanan n = 12, setengah tahun n = 2).
  • Model risiko hipertermia menggunakan fungsi salingan nisbah luas permukaan (6x^2) kepada isi padu (x^3): y = 6/x. Kubus kecil (kanak-kanak) mempunyai nisbah y lebih besar dan kehilangan cecair jauh lebih cepat.
  • Sentiasa nyatakan had domain sah pada langkah penentusahan — contohnya bagi tangki air V(t) = 120 - 8t, domain sah ialah 0 <= t <= 15 minit kerana isi padu negatif tidak mungkin wujud.

Contoh: Sejumlah RM10 000 disimpan dengan kadar faedah 6% setahun yang dikompaunkan setengah tahun sekali (n = 2). Hitung baki selepas 2 tahun menggunakan model pemurnian A(t) = P(1 + r/n)^(nt).

Penyelesaian: P = 10 000, r = 0.06, n = 2, t = 2. A(2) = 10 000(1 + 0.06/2)^(2 x 2) = 10 000(1.03)^4 = RM11 255.09.

Tip Penting: Pastikan kadar r ditukar kepada perpuluhan (6% = 0.06) sebelum membahagikannya dengan n dalam rumus faedah kompaun!

AMARAN PEMERIKSA #1

ELAKKAN: Mengira kos petrol satu hala sahaja dalam model perbandingan pasar raya atau mengabaikan dua kelajuan arus sungai.

TEPAT: Perjalanan ke pasar raya melibatkan dua hala (pergi dan balik), maka jarak s perlu didarab 2; bagi bot di sungai, kelajuan ke hulu ialah (v - c) dan ke hilir ialah (v + c).

Tip Skor Exam: Lakar rajah laluan pergi-balik dengan arah halaju sebelum menulis persamaan jarak.

AMARAN PEMERIKSA #2

ELAKKAN: Menggunakan model kuadratik untuk data penyejukan suhu tanpa menyemak tingkah laku selepas titik minimum.

TEPAT: Model kuadratik memantul naik semula selepas titik minimum dan model linear terus turun bawah paras beku secara tidak realistik; hanya susutan eksponen (0 < a < 1) melandai ke suhu bilik.

Tip Skor Exam: Uji tingkah laku model bagi nilai t yang besar dalam langkah penentusahan sebelum memilih fungsi terbaik.

AMARAN PEMERIKSA #3

ELAKKAN: Lupa membahagi kadar faedah r dengan n dan mendarab tempoh t dengan n apabila pengkompaunan berlaku n kali setahun.

TEPAT: Gantikan r/n dan nt ke dalam A(t) = P(1 + r/n)^(nt), bukannya mengekalkan r dan t tahunan asal.

Tip Skor Exam: Semak kekerapan kompaun dalam soalan: bulanan (n = 12), suku tahunan (n = 4), setengah tahun (n = 2).

Soalan 3 / 20 +10 XP

Dalam kajian kes membeli 2 kampit beras 10 kg (Pasar Raya A = RM25.95, Pasar Raya B = RM23.99, kereta 17.6 km/L, petrol RM2.08/L), apakah penjimatan bersih jika Pasar Raya B terletak s = 6 km sehala, dan apakah jarak maksimum s supaya masih berbaloi?

Huraian: S = (25.95 - 23.99) x 2 = RM3.92. T = (6 / 17.6) x 2.08 x 2 = RM1.42. Penjimatan = 3.92 - 1.42 = RM2.50. Had s < 3.92 / (4.16/17.6) ≈ 16.6 km.

Soalan 4 / 20 +10 XP

Huraian: Samakan jarak hulu dan hilir: 6(v - 2) = 5(v + 2) -> 6v - 12 = 5v + 10 -> v = 22 km j^(-1).

Soalan 5 / 20 +10 XP

Huraian: 45 = k(405) -> k = 1/9, maka y = (1/9)x. Model gagal jika jenis laluan berbeza kerana kadar penggunaan petrol di jalan bandar berbeza daripada lebuh raya.

Soalan 9 / 20 +10 XP

Soalan 10 / 20 +10 XP

Dalam model risiko hipertermia menggunakan kubus bersisi x, kadar kehilangan cecair bergantung pada luas permukaan (6x^2) dan simpanan cecair pada isi padu (x^3), memberi nisbah y = 6/x. Bandingkan nisbah kubus x = 1 dengan kubus x = 6.

Huraian: Pada x = 1, y = 6/1 = 6; pada x = 6, y = 6/6 = 1. Kubus kecil (anak kecil) mempunyai nisbah permukaan per isi padu 6 kali ganda lebih tinggi.

Soalan 11 / 20 +10 XP

Jarak berhenti kereta di jalan kering ialah d(v) = 0.25v + 0.006v^2, manakala di jalan basah jarak brek berganda dua kali menjadi d(v) = 0.25v + 0.012v^2. Hitung jumlah jarak berhenti pada kelajuan v = 90 km j^(-1) di atas jalan basah.

Huraian: Jarak reaksi = 0.25(90) = 22.5 m. Jarak brek jalan basah = 0.012(90^2) = 97.2 m. Jumlah = 22.5 + 97.2 = 119.7 m.

Soalan 13 / 20 +10 XP

Isi padu air dalam tangki yang bocor pada masa t minit dimodelkan oleh V(t) = 120 - 8t liter. Apakah julat domain masa t yang munasabah bagi situasi nyata ini?

Huraian: Pada t = 0, V = 120 L. Apabila tangki kosong, 120 - 8t = 0 -> t = 15 minit. Masa dan isi padu tidak boleh negatif, maka domain sah ialah 0 <= t <= 15 minit.

Soalan 16 / 20 +10 XP

Kabel utama sebuah jambatan gantung dimodelkan oleh y = (1/3000)x^2 + 5 dengan x jarak mengufuk dari pusat jambatan dalam meter. Berapakah jarak terdekat kabel tersebut dari dek jalan (y = 0) dan tinggi kabel pada x = 300 m?

Huraian: Pada x = 0, nilai minimum y = 5 m. Pada x = 300: y = (300^2)/3000 + 5 = 90 000/3 000 + 5 = 30 + 5 = 35 m.

Soalan 17 / 20 +10 XP

Antara situasi berikut, manakah merupakan contoh MASALAH BERSTRUKTUR (bukan soalan terbuka)?

Huraian: Masalah pertama membekalkan kesemua angka tepat untuk pengiraan tunggal (40 000 x 0.45 x 5 = 90 000), manakala tiga yang lain memerlukan andaian pemodelan terbuka.

Soalan 18 / 20 +10 XP

Dalam rumus A(t) = 20 000(1.04)^t bagi simpanan Encik Gomez, apakah yang diwakili oleh nombor 20 000 dan 1.04?

Huraian: Dalam model eksponen y = Ca^x, C = 20 000 ialah nilai awal (prinsipal) dan a = 1 + 0.04 = 1.04 ialah faktor pertumbuhan 4% setahun.

Soalan 19 / 20 +10 XP

Sebuah model fungsi kuadratik y = ax^2 + bx + c perlu diterbitkan daripada satu jadual data eksperimen. Berapakah bilangan minimum titik data tak segaris yang diperlukan untuk menentukan nilai a, b dan c?

Huraian: Kerana terdapat tiga pemalar tidak diketahui (a, b, c), sekurang-kurangnya 3 titik data tak segaris diperlukan untuk membentuk tiga persamaan serentak.

Soalan 20 / 20 +10 XP

Dalam model pertumbuhan eksponen y = Ca^x (C > 0), apakah julat nilai asas a yang menghasilkan lengkung SUSUTAN eksponen?

Huraian: Apabila 0 < a < 1 (cth. a = 0.85), nilai y menyusut secara eksponen menghampiri paksi mengufuk tanpa menjadi negatif.
