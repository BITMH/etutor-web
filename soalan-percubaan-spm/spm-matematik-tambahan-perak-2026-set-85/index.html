Pratonton Contoh Soalan & Skema Jawapan (SET 85)

Berikut ialah 3 contoh petikan soalan sebenar berserta skema jawapan. Buka mod interaktif penuh untuk menjawab keseluruhan soalan lengkap rajah asal:

Contoh 1 • Kertas 2 (Struktur / Subjektif) — Kadar Perubahan Isi Padu & Persamaan Logaritma serta Konjugat Surd [3 Markah]

Soalan 6: Isi padu sebuah bongkah logam, V cm³, diberi oleh V = π(32/r + r³) , dengan keadaan r ialah jejari tapaknya dalam cm. Soalan 7(a): Selesaikan persamaan logaritma: (log₅ 125 - log₉ 9x) / log₉ x = -1 . Soalan 7(b): Sebuah rumah resort berbentuk piramid mempunyai luas tapak (6 + 3√3) m² dan isi padu (30√3 + 12) m³. Hitung tinggi rumah tersebut dalam bentuk (a + b√3) m. — (a) Diberi isi padu bongkah bertambah dengan kadar tetap 0.8π cm³ s⁻¹. Cari kadar perubahan jejari, dalam cm s⁻¹, pada ketika jejarinya ialah 2 cm.

Semak Skema Jawapan & Ulasan Contoh 1
Jawapan Skema: 0.2 cm s⁻¹
Huraian: dV/dr = π(-32/r² + 3r²) (1m) Pada r = 2: dV/dr = π(-32/4 + 3(4)) = 4π (1m) dV/dt = (dV/dr) × (dr/dt) => 0.8π = 4π × (dr/dt) => dr/dt = 0.2 cm s⁻¹ (1m)
Contoh 2 • Kertas 2 (Struktur / Subjektif) — Aplikasi Sistem Persamaan Linear dalam Perniagaan Automotif [6 Markah]

Kertas 2 Soalan 3: Amir merupakan seorang usahawan dalam bidang automotif yang memperoleh pendapatan daripada tiga sumber: pusat servis kenderaan ( x ), jualan alat ganti kenderaan ( y ), dan jualan aksesori kenderaan ( z ). Jumlah pendapatan Amir pada bulan Mei ialah RM21,300. Hasil daripada pusat servis kenderaan apabila ditambah RM1,500 adalah dua kali jumlah hasil jualan alat ganti dan... — (a) Bentukkan tiga persamaan linear dan hitung pendapatan, dalam RM, yang diperoleh bagi setiap sumber (x, y, dan z).

Semak Skema Jawapan & Ulasan Contoh 2
Jawapan Skema: Pusat servis (x) = RM13,700; Jualan alat ganti (y) = RM7,100; Jualan aksesori (z) = RM500
Huraian: Persamaan: (1) x + y + z = 21300 (2) x + 1500 = 2(y + z) => x - 2y - 2z = -1500 (3) x + z = 2y => x - 2y + z = 0 (2m) Daripada (1) dan (3): 2y + y = 21300 => 3y = 21300 => y = RM7,100 (1m) Daripada (1) dan (2): x + 1500 = 2(21300 - x) => 3x = 41100 => x = RM13,700 (2m) z = 21300 - 13700 - 7100 = RM500 (1m)
Contoh 3 • Kertas 2 (Struktur / Subjektif) — Persamaan Lengkung, Garis Normal/Tangen dan Hukum Linear [2 Markah]

Soalan 1(a)-(b): Rajah 3 menunjukkan lengkung y = f(x) dan y = g(x) yang bersilang di titik B pada paksi-x. Fungsi kecerunan bagi lengkung y = f(x) pada titik A(0, 3) ialah 2x + 3 . Garis normal kepada y = f(x) di titik A menyilang paksi- x di titik B . Soalan 1(c): Rajah 5.1 dan Rajah 5.2 (Hukum Linear) Pemboleh ubah x dan y dihubungkan oleh persamaan y / x² = a - b / x . Pintasan paksi... — (a) Cari persamaan lengkung y = f(x) yang melalui titik A(0, 3).

Semak Skema Jawapan & Ulasan Contoh 3
Jawapan Skema: y = x² + 3x + 3
Huraian: y = ∫(2x + 3) dx = (2x²)/2 + 3x + c (1m) Pada A(0, 3): c = 3 => y = x² + 3x + 3 (1m)
